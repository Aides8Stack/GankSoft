# GankSoft v2.1 — 参数、继承、应用与复习队列强制验收矩阵

> 此文件为 Codex **必须实现为自动化断言**的测试清单，不是已执行结果。
> 建议每条有测试 ID、独立合成数据库 fixture、固定 clock/timezone、操作、预期状态和执行结果（pass/fail/not_run）。

## A. 单卡与卡片集继承/覆盖

| ID | 操作/前提 | 必须断言的结果 |
|---|---|---|
| CFG-01 | 新建卡片集且无独立配置 | 默认集最长间隔 365 天、每日上限 15 道，旧卡仍能读取 |
| CFG-02 | 集设置 30 天，卡 Q1 没有 override | Q1 有效间隔是 30，来源 `deck_default` |
| CFG-03 | 集 30 天，Q2 显式 90 天 | Q2 是 90，来源 `card_override`，不受 30 约束（仅受 3650 硬上限） |
| CFG-04 | 集 30→60 天，Q1 继承，Q2 独立 90 | Q1 有效 60；Q2 仍 90 |
| CFG-05 | 清除 Q2 override | Q2 继承集 60，历史复盘不变 |
| CFG-06 | 从集 A 移动到集 B（A=30,B=120） | 继承卡取 120，独立 7 的卡仍 7；原现有到期计划不自动改 |
| CFG-07 | 错题卡目标 80 秒，显式 `none` | 无目标、不做快慢评价；不是回退为集目标 |
| CFG-08 | 卡片集用时目标无设置，单卡自定义 90 | 单卡 90；另一继承卡目标仍 null |
| CFG-09 | 记忆卡打开复习配置 | 可以改最大间隔、不能出现错题答题用时目标或错题型诊断参数 |
| CFG-10 | 输入 0/-1/3651/1.5/NaN/Infinity 等非法天数 | UI 拦截且服务端拒绝，数据库与 revision 不变 |
| CFG-11 | 卡片集每日限 0/201、用时 0/86401 | 服务端拒绝、UI 有具体字段错误 |
| CFG-12 | 跨卡片集同 ID/权限越界或已删除卡 | 不能更改错误对象、不泄露其他集配置 |
| CFG-13 | 旧命令 policy.card.set / deck.set / assessment.target.set | 仍然有效并遵循新单一规则，无重复冲突实现 |

## B. “仅未来生效”与“预览后提前”

| ID | 操作/前提 | 必须断言的结果 |
|---|---|---|
| DUE-01 | 集最大间隔 365→30，选择 `future_only` | 新配置值保存，但所有已存在 plan/scheduling due 不变 |
| DUE-02 | 单卡最大间隔 60→7，选择 `future_only` | 当前 due 不变，下一次有效复习上限为 7 |
| DUE-03 | 最大间隔 30→90 | 保存/advance 均不允许自动延后旧 due |
| DUE-04 | 一张继承卡现有 due 比 last_review+30 天晚 | advance 预览显示应提前；确认后实际有效 due 与预览一致 |
| DUE-05 | last_review+新 cap 已过，原 due 仍未来 | advance 后“现在到期”，不新建过去的 review event |
| DUE-06 | 集 30 + 单卡独立 90 | 集级 advance 不以 30 夹紧该独立卡，卡不应被误改 |
| DUE-07 | 暂停卡、删除卡、首学卡、时间证据缺失卡 | 预览标排除原因；默认不改 |
| DUE-08 | 手动延期到超过上限 | 默认标示冲突并跳过；不得静默取消用户延期 |
| DUE-09 | 先 query preview，比较 SQLite snapshot 文件 | 预览是纯只读，数据、复盘事件、排期 JSON 无修改 |
| DUE-10 | 用户另一次复盘后旧 preview 才点击确认 | 预览过期并拒绝，不套用陈旧 due |
| DUE-11 | 修改配置 revision 后复用旧 preview | 拒绝且提示重新预览 |
| DUE-12 | 同一个 requestId 重复确认 | 操作/受影响卡、审计、回执没有重复 |
| DUE-13 | 网络响应丢失，客户端查询原 requestId | 返回操作已存在/未完成的确定或未知状态，不盲目重复执行 |
| DUE-14 | 模拟事务中断/磁盘写入错误 | 无半成品；如果分批必须可恢复/可准确报部分进度 |
| DUE-15 | 应用 advance 后未再复盘，显式撤销 | 仅删除本操作生成的 override，恢复原始有效到期视图 |
| DUE-16 | 应用 advance 后卡片又完成有效复习 | 旧 advance 不允许再次撤销并覆盖新排期 |
| DUE-17 | `plans.due_at` 与 `scheduling.data.due` 存在历史差异 | UI 队列和复盘服务用**同一权威** dueEligibility，不出现 UI 显示到期但提交判提前 |
| DUE-18 | 改变学习时区、跨午夜、DST、系统时钟回退 | 预览计算稳定，不产生非法日期、重复使用同一请求 |
| DUE-19 | 在未保存配置时试图提前现有任务 | 要求先保存或一次原子确认，防显示与实际策略不一致 |
| DUE-20 | 批量预览 5000 卡 | 分页/汇总正确，不卡主线程、不将全清单一次送 UI |

## C. 保持率、预算与联合推荐

| ID | 操作/前提 | 必须断言的结果 |
|---|---|---|
| SCH-01 | 未设置 desiredRetention | 继续使用 0.90，FSRS 排期回归与 RC2 行为一致（固定时钟/记录） |
| SCH-02 | 集 0.90→0.95 | 下一次有效复盘读取 0.95；当前既有 due、旧 `stability/difficulty` 不重写 |
| SCH-03 | 保持率 0.79/0.98/NaN | 严格拒绝；0.80/0.97 边界有效；记忆/错题两类均正确 |
| SCH-04 | 卡设置 7 天 + 关联知识点高风险 | FSRS 最大间隔仍 7，不因为该知识点强度变成 3 或更小的隐式上限 |
| SCH-05 | 当天同卡四次合法有效复盘 | “当日独立到期题数”占 1，真实 attempts 仍 4，重学预算分账 |
| SCH-06 | 同一 requestId 重放作答请求 | 不重复添加当天题、预算、历史记录 |
| SCH-07 | 专项非到期题复盘 | 默认记练习，不更新 FSRS due/稳定性或新增正常 schedule event |
| SCH-08 | `exclude_specialty` 的知识点与合法到期题相连 | 正常到期题仍入列，仅额外专项排除 |
| SCH-09 | 一题关联 3 个重点知识点 | 队列最多出现一次、预算计一次、知识覆盖不三重加分 |
| SCH-10 | 知识树父与子关联同一题 | 父汇总不重复累计事件/证据 |
| SCH-11 | 严重逾期题和近期反复失败题竞争 | 逾期公平保底生效，不可无限期饿死逾期题 |
| SCH-12 | 修改推荐 preset / 权重 | 同一数据+clock+规则版本得可重现队列；不写 FSRS |
| SCH-13 | 权重负数、总和非 1、NaN | 服务端拒绝；不自动容忍大偏差或展示假配置 |
| SCH-14 | 7/30/90 天历史图表筛选 | 只能改变显式统计窗口，不改变当前全历史诊断或 FSRS 到期 |
| SCH-15 | 跨卡片集同名知识点 | 严格按 deckId 隔离专项偏好、推荐、配额 |
| SCH-16 | 旧 20 次失败但近期多道不同题跨日做对 | 诊断可展现改善；旧错误不会永久锁死知识点 |
| SCH-17 | 一道题同一天做对十次 | 单题可变好，但知识点不能据此成为“高可信稳定” |
| SCH-18 | 多知识点题明确只在 K2 犯错 | K1 不被错误归因为负面；旧历史快照不完整时显示 unknown |
| SCH-19 | 用户没有任何复习历史 | 展示证据不足，不能输出虚构的掌握概率 |
| SCH-20 | 高级模型 halfLife 改变 | 仅重新计算派生诊断/缓存，原事件和 FSRS 未改，规则版本有记录 |

## D. 数据完整性、协议和交付

| ID | 前提/操作 | 必须断言的结果 |
|---|---|---|
| DAT-01 | 从 v0.7.1 RC2 合成 DB 增量迁移 | 原卡/集设置及历史均不丢失，数据路径仍为 v060/data |
| DAT-02 | 旧备份恢复到新版本 | 缺失的新字段使用明确默认，不造成 schema 错误 |
| DAT-03 | 新版本完整备份与恢复 | 新配置表、知识点专项偏好、due override、操作审计及复盘历史无损恢复 |
| DAT-04 | 只导入/导出内容 ZIP | 不宣称包含调度/学习历史/高级配置，遵守原内容交换协议边界 |
| DAT-05 | 知识点删除/软删/合并 | 保留必要快照/追溯，孤儿配置给显式提示，不泄漏跨集 |
| DAT-06 | CLI/API 错误或 IPC 未授权 | 不能通过任意 API 绕过校验、审计、配置作用域 |
| DAT-07 | 页面同时发多个配置预览请求 | 旧响应不覆盖更晚版本的 UI，未保存编辑草稿不丢失 |
| DAT-08 | 真实 Windows 未执行 | 报告 Windows 状态为 `not_run`，不得引用 Linux 自动化声称 Windows 通过 |
| DAT-09 | 最终 Windows 压缩包 | ZIP 内含真实 runtime/native 依赖，最终 ZIP 自身经校验，不只校验未压缩目录 |
| DAT-10 | 大数据模拟性能 | 预览分页、延迟/内存有记录，队列缓存按配置/数据/时区规则有效失效 |
