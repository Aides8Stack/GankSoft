# GankSoft v0.6.3：知识图谱交互改造与验收

日期：2026-10-17。交付级别：RC。基于现有 v0.6.0 RC 源码增量实现，延续 v0.5.1 的业务模块和 PickQ 设计参考。版本直接进入 v0.6.3，不虚构 v0.6.1/v0.6.2 的交付历史。

## 问题与需求

| 编号 | 问题 | v0.6.3 的行为及验收标准 |
|---|---|---|
| KG-01 | 右侧知识点细节栏覆盖导图节点 | 取消绝对定位；画布与详情在独立区域内排版，边界不得重叠。工作区宽度不超过760 CSS像素时，详情放在画布下方，支持独立滚动和收起。 |
| KG-02 | 当前导图操作空间小，缺少完整操作入口 | 画布右上角增加“展开导图”；进入占满应用内容窗口的思维导图工作台，具备搜索、定位、适应窗口、回到中心、新增下级、撤销、重做、保存及知识栏功能。点击“返回知识图谱”或在非输入状态按Esc返回。 |
| KG-03 | 无法通过鼠标左键平移导图 | 左键按住空白区域平移，显示抓手；松开、取消指针或窗口失焦时终止。节点拖动继续用于调整层级，拖放手势结束后才更新详情栏以免目标位移；双击改名、右键菜单继续可用。 |
| KG-04 | 模式切换可能丢失编辑 | 普通/展开模式复用同一组件与MindElixir实例；节点、选中项、缩放、撤销记录及未保存修改保留。容器尺寸变化时平移补偿，使画布中心位置稳定。 |
| KG-05 | 知识栏应能主动管理 | 选中已保存节点且鼠标手势结束后打开知识栏；可通过“收起”关闭和“打开知识栏”恢复。无已保存节点时按钮禁用；新节点保存后再编辑其详情。 |

“大图”是应用内完整工作台，不是新窗口或系统F11模式。长导图允许通过平移/缩放浏览；“无遮挡”指细节栏不覆盖画布，并不要求所有节点同时缩放到屏幕内。

## 模块实现与复用

- `MindMapWorkspace.vue`：维护视图模式、知识栏显示状态、草稿和选中项，继续使用既有服务。
- `src/composables/mindMapPan.ts`：仅补充可编辑导图的空白区域左键手势，使用MindElixir的`move`接口；不重写布局、连线、节点拖动、缩放和撤销引擎。
- `style.css`：Flex分栏与容器查询实现响应式布局，详情栏移出画布；展开模式通过固定工作区扩大尺寸，编辑弹窗继续位于其上层。
- `KnowledgeEditor.vue`：继续复用已有知识点详情编辑器。
- `KnowledgePicker.vue`：关联/筛选继续共用已有知识点选择器。本次没有另造数据入口。

## 前后端协议

界面扩大、收起知识栏及平移均为本地视图行为，不产生写请求。新增或调整节点仍通过类型化客户端调用`knowledge.map.save`；既有版本校验、事务和冲突处理继续生效。详情编辑使用`knowledge.save`，读数据继续使用统一`workspace.read`。筛选关联卡片继续使用既有筛选预设及卡片页。

软件版本更新为0.6.3；协议2.0、数据库schema600、内容包协议和`v060/data`空间维持现有实现。UI改造不要求数据库迁移或第二套协议，也不引入旧版兼容层。

## 调用状态与约束

| 状态/事件 | 结果 |
|---|---|
| 普通模式 → 展开 | 同一导图实例扩大，聚焦返回按钮，保留草稿与当前选择 |
| 展开 → 返回/Esc | 恢复普通布局，焦点返回展开按钮，不自动提交或丢弃草稿 |
| 未选中节点 → 选中已保存节点 | 打开详情；普通/展开都遵守同一占位规则 |
| 详情打开 → 关闭 | 释放画布空间，保留选中节点，可重新打开 |
| 空白区域左键按下 → 移动 → 松开 | 只改变视图位移；不置脏，不改变知识树 |
| 节点拖动/新增/改名 | 使用现有引擎标记草稿；点击保存才写入业务数据 |
| 保存失败或版本冲突 | 保留未保存状态，由既有错误区提示；不会假报保存成功 |
| 草稿未保存时编辑详情 | 沿用禁用策略，避免详情刷新覆盖导图草稿 |
| 组件卸载 | 释放指针捕获、事件监听器、ResizeObserver和导图实例 |

## 验证方式与交付限制

`npm run check`验证业务测试、协议边界/类型、56项契约导出及生产构建。`npm run smoke:mind-workspace`覆盖宽窄窗口无重叠、空白左键平移不置脏、展开/详情编辑、草稿往返与Esc返回、节点层级拖动及持久化。`npm run test:package`在ASAR成品中重跑导图和既有学习/知识点选择/筛选交互。

本次执行结果见`validation-results/check-v063.log`、`mind-workspace.json`及`package-v060.json`（沿用工具文件名，结果内标识0.6.3）。历史v0.6.0文档和证据保留，不能当作本版本Windows实机结果。

Windows ZIP包含GankSoft.exe、运行库、资源及原生图像模块，完整解压后运行。包内应用元数据和EXE版本资源均更新为0.6.3。Windows10/11实机执行尚未完成，本交付仍为RC；运行`tools/validation/windows-test.ps1`可在目标系统执行成品验证，正式发布继续受双系统验收门禁约束。
