# v0.4.11 固定题目与逐次复盘记录

## 数据边界

一张错题卡的题干、选项、正确答案、解析属于题目内容。正常复盘只读取这些内容，不写回题目，不覆盖它们。

每次复盘独立追加一条记录：本次选择的答案、自评分、做题用时（秒）、原始思路、解析后感悟（可选），以及正误、错因、知识漏洞和当次调度结果。感悟为空是正常情况，不阻止提交。重试继续使用原编号，不生成重复记录。

题目可在编辑功能中主动纠错；编辑会创建新的内容版本。历史记录继续读取当时快照，避免用新选项、答案、解析或图片替代旧题目。没有完整快照的旧记录明确显示缺失，不从当前内容补齐。

## 用户入口

打开题目项目页或复盘界面的「查看复盘数据与变化」：

- 自评分走势与用时走势按同一复盘次序排列，单位分别是分和秒。
- 默认包含每次保存的记录，包括练习／同日巩固；实心点表示有效复盘，空心点表示练习／巩固。
- 勾选「图表仅看有效复盘」可过滤练习点。该过滤不修改历史，不改变调度。
- 点击数据点，或用 Tab 聚焦后按 Enter／空格，选中该次复盘。两张图联动高亮同一记录。
- 选中记录直接显示当次选择、当时的正确答案、完整文字选项、题目图片、做题思路和可选感悟。题干、原始解析及解析图片可展开查看。
- 明细表显示每次分数、用时、调度等级和当时排期，点击「查看详情」也能选中记录。
- 平均用时和累计用时包含所选版本范围内所有有用时的记录，含练习；有效正确率与有效平均自评的原有口径不变。
- 单一内容版本内绘图，全部版本用于历史总览，不跨改题前后连线。缺失数值保持留空，不按零补齐。

横轴按复盘先后顺序，并非等时间间隔。自评分纵轴为 0—10 分，用时纵轴根据秒数自适应；0 秒按已保存的原值显示，未记录则留空。空数据、单条数据和多次复盘均有独立显示逻辑。

## 模块化边界

| 模块 | 输入／输出 | 约束 |
| --- | --- | --- |
| 题目内容模块 | 当前题干、选项、答案、解析和内容版本 | 正常复盘不修改；主动编辑时保留历史快照 |
| 复盘写入模块 | 作答命令 → 独立复盘记录 | 逐条追加、幂等重试；与会话及正式调度原子提交 |
| review/analytics.ts | card.reviewStats → CardReviewStats | 只读记录和当时快照，不导入或调用 FSRS、配置保存、会话写入模块 |
| shared/review-analytics.ts | 历史记录与统计 DTO | 明确区分题目快照、单次选择、自评分、秒数和调度等级 |
| shared/review-series.ts | 数量化记录 + 指标名 → 坐标、线段和刻度 | 纯函数，无 Vue、数据库、IPC 或调度依赖，不修改输入 |
| ReviewLineChart.vue | 数据 + 指标 + 选中编号 → select 事件 | 只展示与选择，不发起存储或调度请求；两张图共用 |
| ReviewRecordDetail.vue | 单条记录 + 卡片类型 → 只读详情 | 只展示原始选项、思路、感悟，不依赖 API 或全局学习状态 |
| CardReviewAnalytics.vue | 卡片编号／类型 | 负责加载、版本选择、图表过滤与联动，不承担调度计算 |

调用方向为：统计窗口 → 只读统计 API → 记录／历史快照。API 输出 DTO 后，窗口将其交给图表和详情组件；图表通过 select(id) 通知窗口选择记录。图表、详情和调度引擎彼此不直接调用。

已有调度模块继续独立工作：policy 解析配置，fsrs 计算排期，workflow 协调原子提交。查看或筛选统计数据不会重新计算下次时间。

## 验收结果

`npm run check`：87 项通过，包含新增 4 组测试：

1. 同题多次保存不同分数、答案、用时、思路和可选感悟，固定内容不变；重试不重复，统计只读。
2. 修改当前选项和答案后，历史仍读取原始选项、答案与解析；缺失快照不使用当前内容替代。
3. 图表缺失值断线、零值、单点、多次复盘、自适应秒轴。
4. 图表模型纯函数不修改输入，得分和秒数独立，缺失用时不按零补齐。

`node tools/smoke-timeline-v0411.mjs`：实际 Electron 验证每次复盘都出现在两图、点击及键盘选择、原选项和思路、感悟为空、过滤、平均用时、版本切换、只读历史与 980／1500／1920 像素布局。

`tools/smoke-review-v0410.mjs` 已适配新图表与感悟标签；继续验证两层配置、自评分滑块、草稿重启恢复及记忆卡设置。`tools/smoke-reliability-v048.mjs` 保留响应丢失重试、内容冲突、备份恢复验收。

数据库仍为 schema 7，不新增历史存储格式。新图表和统计读取原本已保存的数据，完整备份继续保留记录、快照、图片和配置。
