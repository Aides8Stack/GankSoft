# GankSoft v0.6.4 RC：批量导入与卡片列表修复

基于v0.6.3 RC增量修复。知识栏分栏、大图工作台、左键平移已保留，不更换导图库。本次没有数据库迁移，继续使用协议2.0、schema600、v060/data。

## 问题与实现

1. 文件选择：原界面标注.gank.json，但Electron对话框仅放行ZIP，读取器也仅解压ZIP。现对话框提供JSON/ZIP组合及单独过滤项；JSON支持UTF-8 BOM，仍必须为ganksoft.content / 2.0。JSON与ZIP共用validatePackage及图片校验，保留128 MB上限。旧1.0协议未增加兼容，错误格式会拒绝。
2. 列表可见性：复现步骤为在“所有卡片”选择“已学习”，进入批量导入，导入12张未学习卡，再查看汇总为12张而列表为0张。原因是explorerViews保留旧筛选，不是该复现中的导入写入失败。未取得用户实际数据包和数据库，其他输入特有问题不能据此排除。
3. 导入成功后通过store.resetExplorerView清理当前集的筛选、预设和选择，其他卡片集筛选保留；新增“查看卡片”入口。所有卡片默认及清空筛选均包含暂停卡片，明确展示“本集总数/符合条件数”，被筛选隐藏时显示数量和“显示本集全部卡片”。用户手动设置的筛选在普通页面切换中继续保留。重复导入仅返回原报告，不复制或恢复已删除卡片。
4. 界面协议说明修正为ganksoft.content / 2.0，examples/README同步说明JSON可直接导入。

## 实现入口

- electron/main.ts：文件对话框扩展名；仍通过唯一protocol桥调用。
- electron/modules/imports/container.ts：按JSON扩展名解析并校验；其余ZIP路径维持清单、附件与哈希校验。
- src/store.ts：resetExplorerView；src/components/ImportWorkspace.vue：导入成功重置及跳转入口。
- src/components/CardExplorer.vue：默认暂停范围、总数与隐藏提示、共用清空筛选处理。
- tests/containers-v060.test.ts：JSON/ZIP等价、BOM、错误JSON/协议/图片拒绝。
- tools/smoke-import-cards.mjs：6组端到端回归，已纳入package-check和windows-test.ps1。
- tools/validation/artifact-code-check.mjs：EXE/ASAR版本与构建字节一致性静态检查，不执行Windows应用。

## 用户复验

完整解压本版Windows ZIP，运行GankSoft.exe。在目标卡片集中进入批量导入，可选择.gank.json或.gank.zip，预览后确认；点击“查看卡片”，数量应与汇总一致。若手动增加筛选，列表应显示隐藏数量并可一键显示全部。

如仍复现，请保留导入包及具体卡片集/筛选状态以进一步排查，不需要重复导入或删除已有学习数据。Windows正式版放行仍需双系统windows-test.ps1、W01—W18人工签核、相同成品哈希及release:verify通过。
