## 用户已明确批准的草稿规则

**任何新卡发生编辑**就必须自动保存一份草稿；**任何已发布卡再次编辑**也要自动保存与原卡片 ID 绑定的修改草稿。无需用户点击「保存草稿」。草稿要在所属卡片集的草稿箱 UI 中可见、可继续编辑、可跨进程重启恢复。保存草稿不能提前改变已发布内容、学习历史或 FSRS，也不能重复创建第二张已发布学习卡。允许短防抖，失败必须保留正文并明确提示。

## 必须实际做的工作（优先级和连续执行）

### 第一阶段：P0 草稿功能和粘贴实测闭环

1. 从正式 Electron UI、新的隔离 Schema606 库执行 `NEW-01..19` 和 `OLD-01..14`，用鼠标和键盘编辑三种模式，不只是调用 `draft.save`。同卡片集与多卡片集、未发布/已发布、手动输入/粘贴均验证。**特别要求从草稿箱界面点进草稿、跨 Electron 进程重启再进入**。
2. 如果已有功能出现 FAIL：立即定位源码，包括 `UnifiedWorkspace` 草稿箱渲染、`CardDraftController`、`CardDraftForm`、`new-drafts`、`draft-service`、Markdown 富文本 `handlePaste`、保存回执与异常路径；最小修复后执行同场景及关联回归。不要简单放开危险 HTML 或绕过安全协议。
3. 执行 `CLIP-01..16`；Windows 物理剪贴板当前环境不可用时先用受控 Electron UI+系统 clipboard API 做自动验证，并记录未通过真实 Win10/11 的项为 `NOT_RUN`。不把直接 `DataTransfer` 合成的 paste 当作真实系统剪贴板通过。
4. 每项实际结果写入 `E2E-RESULTS.json` 对应平台状态及 evidence、testedSha、issue、fixSha；首次未跑仍是 `NOT_RUN`。同时把真实失败更新 Issue #16、#17，完成 #19 自动草稿合同验证。

### 第二阶段：P0 数据完整性、复盘历史和安全

执行 `REVIEW`、`BACK`、`TRASH`、`FAULT` 高优先级流程（详见操作链原文件）。每条通过 UI 操作并对照只读存储证据；删除、备份恢复、数据迁移及未知回执必须零写/幂等核验。出现真实 BUG 按当前阶段连续修复。

### 第三阶段：P1 其他功能操作链

按 `CAT`、`EDITOR`、`LIST`、`PLAN`、`KNOW`、`MD`、`MEDIA`、`EX`、`WIN` 各组执行，再覆盖 `ENV`、`HOME`、`AN`、`SET`。每个正式页面与可操作按钮/输入/菜单/右键/对话框都映射到至少一个 ID，漏项补用例，不允许仅因为已经有很多条测试而跳过核心功能。

## 模拟人工的硬性要求

- **驱动真实前端**：现有 Playwright `_electron.launch`，复用 `tools/validation/r7/integration.ts` 等已有正式生产 Electron 工具。按钮用可访问名称/稳定 data-testid 点击，内容用真实键盘、选区操作；表格要有真实指针事件。预置的合成数据库可以用 fixture，但不能通过后台 API 写业务结果并冒充用户操作成功。
- **每条主流程必须闭环**：打开→动作→状态/保存→离开→草稿箱或列表找回→重新打开→新进程重启读回。取消/回滚/冲突还要比对前后持久快照，异常不得静默“修复”或删掉校验。
- **故障直接处理**：FAIL→最小复现→定位业务/组件/夹具→修复→专项重跑→相邻场景回归→验证跨进程持久化→更新 Issue、结果账本与代码提交。连续处理同阶段发现的问题，无需逐项问用户；不能因一个小 BUG 就停止整组验收。
- **每个环境独立报 PASS**：UNIT/API、Linux Electron、Windows CI、Win10 真机、Win11 真机，不得相互顶替。手头没有 Windows 就不能宣称物理剪贴板与 IME 验收通过。
- **严格 vs 宽松**：数据丢失、草稿不可见、核心功能、历史/FSRS、删除/备份、安全为阻断；合理 DPI、颜色、轻微像素偏差不单独阻断。不新增大规模截图上传或视觉逐像素测试。
- **节约额度**：一次 Work 优先完成当前 P0 闭环及能自主修复的错误，按实际额度保存可恢复检查点；后续 Work 直接从结果账本首个 `NOT_RUN/FAIL` 继续，不重复审计已通过结果。无需全量读取 R0–R7 旧报告。
- **避免假结果**：每个 PASS 需真实执行命令、SHA、数据校验结果；未执行维持 NOT_RUN；定位未充分的继续 FAIL/BLOCKED，不以“代码看起来对”代替执行。
