# v0.7.3 RC Windows 实机验收

Win10：not_run。Win11：not_run。旧v0.7.1 RC2的用户Win11反馈不能作为本版通过。

升级前在旧版完整备份并退出。将本版Windows包完整解压到新目录，不能仅复制exe；首次打开原数据后schema升级604，回退须使用升级前备份。

先执行沿用 `docs/v0.7.2-windows-acceptance.md` 的 W01—W30（针对本版新ZIP重新执行），再完成：
