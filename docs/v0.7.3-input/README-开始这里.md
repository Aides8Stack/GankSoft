# GankSoft 自适应复习系统 v2.1 — 分级参数配置与 Codex 实施包

**交付类型**：完整设计规范 + Codex 编码指令 + 自动验收矩阵 + 配置 JSON 示例 + v2 设计基线及源码审查参考。

**状态**：本 ZIP 仅包含**设计和指令文件**；没有修改 GankSoft 应用代码，也不包含 Windows EXE。不要将这些文件的存在误认为新功能已实现或 Windows 已验收。

**目标**：让用户能独立管理每个卡片集/单卡片的最长复习间隔、每日任务预算、答题用时目标，以及自适应复习 v2 的推荐模式、保持率、知识点专项强度和高级诊断参数，同时实现安全的生效预览与既有计划处理。

## 最重要的功能边界

1. **单卡间隔 override > 卡片集间隔**：卡片集最长 30 天，某张卡可独立设置 90 天；用户清除单卡 override 时才恢复继承。
2. **区分参数保存与修改现有到期**：默认“仅今后生效”；如想提前已排期的过长任务，必须预览并再次确认；只提前不自动延后；有用户显式延期冲突时默认跳过。
3. **FSRS 与知识点专项分离**：知识点薄弱提高专项推荐，但不偷偷改变相关题的 FSRS 排期。保持率修改从后续有效复盘生效，不重写历史。
4. **不固定三次**：自适应风险使用全部适用历史、时间衰减、跨题跨日证据与可信度；30/90 天是 UI 统计筛选，不是诊断硬截止。
5. **保护数据和工作区**：旧 schema601 数据在 v060/data，实际迁移只增不删；保留未提交工作；旧 ZIP、旧路径不能替代用户现有新源码。
6. **状态诚实**：v0.7.1 RC2 部分基础参数已经实现，但 ZIP 中 v2/v2.1 新功能仍为“设计/待实现”；Win10/11 实机未测不记为通过。
