## 实际环境与限制

- 开发与端到端验证在 Linux 上进行，Electron 使用 headless Ozone 后端。测试专用环境变量 `GANKSOFT_E2E=1` 关闭单实例锁，仅为适应测试环境的 Unix socket 限制；正常启动保留单实例锁。
- Windows 包通过跨平台打包生成，尚未在用户的 Windows 系统上完成运行、剪贴板与系统凭据加密的真实验收。
- 模型连接使用模拟服务响应验证请求、异常与返回格式，未使用用户密钥调用真实模型。
- 本地统计和间隔规则是可配置的 MVP 实现，没有宣称经过长期记忆效果验证。
- 尚未做大规模数据性能测试；数据量增长后应增加分页与局部图谱查询。
- 安装依赖可能显示 Electron Forge 间接工具依赖的弃用提示；本交付不宣称通过完整依赖安全审计。

## Windows 首次验收建议

1. 解压便携包，打开 `GankSoft.exe`；或在源码目录运行 `start.cmd`。
2. 建立两个知识点并连接，录入一道题关联二者。
3. 添加题目图片与解析图片，检查显示。
4. 重做一次，检查评分、下次复盘及重启后的保留情况。
5. 合并知识点，检查题目关联和历史错因。
6. 导出完整备份，并恢复检查。

如遇问题，保留错误信息与版本号。不要删除学习数据目录。
