# v3.7 后续已确认补充要求（覆盖相冲突的演示行为）

## 全局布局
- 直接承接原型的绿色系视觉 token、内容布局、排版、卡片、表格、控制条、导航层次和空态。
- 用户确认**左侧窄图标导航**，工具栏统一图标化、中文悬停/焦点提示；不能改回原型的常驻宽传统侧栏。窄导航之外仍须有明确卡片集选择入口、子导航和功能定位。
- 用户主要流程：选择卡片集 → 卡片集概览 → 学习/复盘、分析、知识点、编辑、调度。默认主界面“学习总览”，不得直接暴露大堆散乱按钮。
- 布局不拥挤，文字层级统一；屏幕宽窄变化不截断操作。用户最新对简陋主页的实际截图是不达标证据。

## 卡片/复盘/数据
- 卡片集树形文件夹，卡片集**不包含子卡片集**。三种卡片：错题单选、问答记忆、直接记忆；只有错题单选/判断，不恢复多选/自由作答。
- 复盘记录独立保存每次选项、原思路、错因、知识漏洞、反思可选、评分 0-10、用时和时间戳；折线图可查看评分/用时，历史可以逐次回看。
- FSRS Again/Hard/Good/Easy，答错强制 Again；单卡/全局调度与参数修改后的排期策略保持原协议。
- 多标签复盘、总计时可暂停、离开自动暂停、不同复盘集不重复；选择卡片/指定知识点/随机/时间范围主动复盘。
- Markdown 编辑即时预览、图片粘贴入资源区、独立缩放、LaTeX、自动保存；保留成熟 Milkdown/Crepe 组件，不换演示编辑器。
- 导入/导出/移动/复制/合并、回收站、防止删除引用图片都维持现有真实行为。

## 知识图谱（重要，单独作为 P4 必验）
- 图谱以每个卡片集为单位；多根节点支持。
- 图谱**全屏铺满应用内容窗口**，不设旧版固定画布高度；节点画布在内容区占尽可用空间，搜索/工具栏保持清晰；宽 1500px 和窄 900px 人工核对。
- 空白画布左键拖动平移，缩放、搜索、定位；节点选择、改名、Tab 子节点、Enter 同级节点；普通节点拖动改变父子关系及同层顺序。
- **暂不要求根节点拖动整张图**，避免复杂自由坐标算法。不要将它误当作普通节点移动验证。
- 工具栏选中节点“新增子节点”“新增同级节点”两枚图标，紧跟 **全屏** 按钮后，与其余工具栏图标同一连续操作带；不能隔在最右边；窄屏可换行但不遮挡。
- 悬停或键盘聚焦显示中文 tooltip；选中节点详情轻量，无左侧重复知识树。
- 每个节点 Markdown 正文真实读写，右侧大纲按真实 parentId 逐级缩进约 18px 级差；导入右侧来源与大编辑区，左侧选择挂载节点；导出先选节点再显示可勾选范围。
- 知识树导入前必须展示差异；整体/部分导出，节点拖动顺序与层级、删父整树入回收站、恢复重名/缺父冲突保留。
- 多对多知识点与卡片关联，父节点掌握度汇总后代关联卡片；历史复盘保存当时知识点快照。

## 冻结技术边界
- Schema 606 正式生产；原 604 仅留隔离源码和测试，不恢复生产路径、不做 604→606 自动迁移。
- S8.b 外部数据库独立追加被取消，生产完全不可调用；不作为 UI 入口。
- 数据本地保存，首次启动不得额外下载或缓存，列表优先摘要+按需详情；不依赖网络 CDN 资源。
- Windows 10/11 同一个便携 ZIP，顶层 `GankSoft/`，包含 `GankSoft.exe`；Release 须单独授权。
