- Reference screenshot：**原版** v3.7（如旧 HTML 的 213px 左栏，记录“用户后续窄图标栏”差异，不判缺陷）。
- Actual screenshot：**正式生产** Electron Windows，来源、SHA、尺寸、是否空库/合成库。
- Diff notes：结构、布局、交互、可访问性、是否使用真实 API；不可把颜色完全一致当作唯一标准。原型按钮功能必须接入真实业务或说明确实不可移植的演示语义。
- Status：`PASS` / `FAIL` / `NOT_RUN` / `BLOCKED`。任何核心项 FAIL 都不能标记 `UI_V37_DONE`。
- 未通过项目按 P0 功能阻断、P1 结构/信息缺失、P2 纯视觉细节分级。
