# W8 — AI 离线导入导出定向验收清单

**全部是未来正式实现验收计划；当前 W8-01～W8-16 均 NOT_RUN。** Vue 原型交互模拟及文档静态核查不计生产测试 PASS。每个 CASE 记录真实被测源码 SHA、环境、步骤、实际断言和回执。

| CASE | 场景 | 必须核验 |
|---|---|---|
| W8-01 | 默认 W4 AI 导出 | 全卡/全历史/完整知识关系，日期只限摘要；Prompt版本/图片选项按实 |
| W8-02 | 导出后切回分析或卡片页 | 同一 job 继续，任务栏展示真实阶段/卡数/事件/字节，未校验不报成功 |
| W8-03 | 中途取消/退出/失败 | 主进程清理临时文件，旧目标不受损，重启无伪完成包 |
| W8-04 | ZIP来源自动找到 | 用户只选 AI 返回 ZIP；仍重验原 W4 包 CRC/哈希/manifest/修订，禁止仅凭文件名 |
| W8-05 | 原始包丢失/移动/未记录 | 一次补选原 W4 ZIP，成功后预览；补选取消零写 |
| W8-06 | ZIP伪造/来源不匹配 | 拒绝恶意/错误文件，原始学习数据和调度完全不变 |
| W8-07 | 默认合法项与冲突 | 合法默认勾选，冲突/拒绝不可选；跨页取消/全选集合正确且去重 |
| W8-08 | 自动 prepare 和一次确认 | 点击应用自动只读核对；取消最后确认零写；成功仅一次整组事务 |
| W8-09 | revision/epoch/到期变化 | 旧 preview/preparation 失效；导入/预览/执行前出现强制重新分析弹窗，暂不处理后仍不能应用，零业务写入 |
| W8-10 | 回执未知/重复点击/SQL失败 | 用原 requestId 查询，重复无二次写；全有或全无回滚 |
| W8-11 | 应用日志与撤销 | 正确记录实际动作数和卡数，后续复盘阻止覆盖新的 FSRS/排期 |
| W8-12 | 三宽、回退、键盘和 Windows | 900/1366/1600无溢出，返回/任务提示可用；真Win10/11和125%DPI单独验 |
| W8-13 | 数据库变化后的完整重分析闭环 | 弹窗从后台数据变化事件触发；重新导出新 W4 ZIP、旧 AI ZIP 仍失效、用户选择 AI 针对新源生成的 ZIP 后才可校验；最终事务发现并发变化时同样拒绝且引导重做 |
| W8-14 | 父子页面导航、遮罩和状态保存 | 真实 UnifiedAnalytics.vue → 子页面；返回后父页 dimension/date/scope/search/sort/direction 保留；弹窗遮罩不覆盖应用主导航与左窄栏；Tab/Escape/焦点恢复有效 |
| W8-15 | 真实进度和导出并发写入 | 原 export.status 没总量时只显示真实 phase/count/bytes、无伪百分比；写入完成但校验未完不报成功；导出中又复盘导致 fixed snapshot 过期时提示需重新导出 |
| W8-16 | 新旧 AI ZIP 严格隔离 | 旧数据变化 → 重新导出 W4 → 再选旧 AI ZIP 必须拒绝 → 外部 AI 重新生成对应新 source ZIP → 严格验证后才允许新 preview；不可通过切换 UI 状态、回退、刷新解锁 |

测试输入使用隔离合成 Schema606，不读取真实用户库；关闭主动补传 AI、无非法动作能力。每项实际日志、被测源码 SHA、测试系统和 NOT_RUN 单独记录在 RESULTS。

## 每项必须执行的四段式证据

1. **准备**：隔离 Schema606 合成库/知识点/卡片/复盘记录，生成经签明身份的原始 W4 ZIP 和建议 ZIP（不使用真实隐私数据）。
2. **操作**：通过正式 Vue → services → IPC → 主进程，模拟点击/文件选择/返回/数据变化/确认；不只测领域函数。
3. **断言**：检查显示状态、源 manifest/CRC/hash/revision、实际 SQLite 全表或受影响字段哈希与 W5 全有或全无回执；拒绝/未知结果不得虚报已执行。
4. **记录**：CASE ID、输入夹具、步骤与断言、进程/屏宽、运行命令、被测源码 SHA、PASS/FAIL/BLOCKED/NOT_RUN、重启读回及异常日志；未跑 Windows 实机单独 NOT_RUN。

**必须专项核查**：W8-09/13/16 的同一 stale 事件只弹一次，取消弹窗仍锁定；W8-03 导出取消和 W8-10 未知写回执是不同机制，禁止合并错误状态；W8-14 子页弹窗不盖主导航；W8-15 无数据分母不显示假进度比例。
