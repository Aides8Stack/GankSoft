# v0.7.3 RC 使用说明

1. 先在旧版进行完整备份，退出后完整解压新包。普通使用不需要Node或npm。
2. 打开卡片集→复盘调度设置。原卡片集最大间隔和每日独立题数保留；下方复习参数提供排期、任务、推荐、知识点专项。单卡独立间隔可长于集默认值，取消独立后恢复继承。
3. 保存配置默认只在下一次有效复盘使用。保持率不是掌握率；建议先保持0.90。
4. 想提前过长现有任务：先保存→查看生效预览→核对分页明细和跳过原因→确认提前。只提前、不延后，暂停、显式延期和首学跳过。未再复盘或人工编辑前可撤销该次提前。
5. 自动“开始复盘”使用服务端联合到期队列，正常到期、同日重学分别计预算。设置页可预览原因，并开始额外知识点专项；该入口只记录练习，不推进FSRS。
6. 知识点强化/减少/排除只作用额外专项，不取消正常到期。诊断会说明独立题数、日期和证据不足；旧数据缺少关联快照时不会猜测掌握情况。
7. 设置→高级诊断模型可以调整半衰期、重复递减和单题贡献上限，仅重算诊断。7/30/90天图表范围不改变当前全历史诊断。
8. 完整备份包含配置、学习史、排期覆盖和图片；内容导出ZIP仍只是内容。升级库不能直接交给旧版，回退请恢复升级前备份。

本版仍为RC，等待Win10/Win11实机验收。参数为可调工程初始值，尚未使用真实用户数据校准。
