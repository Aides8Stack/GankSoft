## 最新最终布局

**删除原弹窗下方常驻的「全部知识点」网格/勾选列表**，仅保留下列五个固定分区：

1. **标题行**：「选择知识点」、必要的单句提示、右上关闭。
2. **知识图谱选择视口**（高度优先）：可拖拽平移、滚轮缩放、适应窗口；单击节点进行选择/取消。
3. **已选知识点（N）**：列表以标签/chip展示本次已经选中的节点，每个标签有 `×` 删除，选中计数同步；可“清空选择”。
4. **搜索知识点**：一行输入框 +「搜索定位」按钮。点击按钮**或按 Enter** 执行同一定位逻辑。下方没有「全部知识点」常驻区域。必要的同名结果候选用**悬浮**小列表展示完整父子路径，不能把页面撑长。
5. **固定底部操作**：「取消」「确认关联」；始终可见，且含已选数量。

弹窗外框本身**不得上下滚动**。图谱只是局部视口：可独立平移、缩放，不是通过滚动整张对话框查看。选中标签很多时允许**标签区域内部**独立滚动；搜索候选若过多允许悬浮层内部局部滚动，不得推动其他分区上下移动。在 1366×768 与 125% Windows 缩放下也应尽量保持弹窗和按钮全部可见，不出现内容被截断；缩减图谱可用高度而不是让整弹窗滚动。

## 单击图谱的多选状态机

- **节点未被选中** → 单击该节点，加入本次选择；图谱节点显示清晰的选中样式，已选标签立即出现，计数 +1。
- **节点已经选中** → 再次单击同一节点，将其取消；图谱样式还原，标签立即移除，计数 -1。
- 在下方点击某个已选标签的 **×** → 仅移除**该知识点 ID**，上方图谱对应节点即时取消选中；不得按重复名称误删其他同名节点。
- “清空选择”清空弹窗临时选择状态，不触碰外部已经提交的关联，除非用户随后按「确认关联」。
- **取消/关闭弹窗**：放弃本次未确认的选择更改，原卡已有的真实关联保持不变。**确认关联**：只按真实 ID 提交一次确认后的选择结果，不误建/删卡、知识点或另一条记录。
- 结构根节点仅表示图谱，不当作普通可关联知识点；多选是非破坏性的关联选择，不要执行知识点删除、节点移动等编辑命令。

## 搜索定位（不要自动选中）

- 用户输入知识点名称或别名，点击「搜索定位」或按 **Enter**：图谱**自动居中/聚焦到该知识点**，必要时将画布缩放至可读比例，并短暂加强定位高亮。**搜索定位不调用 `pick`、不修改 `chosen`、不向已选列表加项目。**
- 找不到：在弹窗可视区域中央弹出**“知识点不存在”**，半透明圆角短消息约 **1–1.3 秒**后自然消失；连续搜索错误重新触发并重置计时，旧计时器不得提前清除新提示；保持输入值且不修改节点关联。
- 同名知识点：用「父节点 / 子节点 / 节点名称」完整路径区分，自动定位一个匹配位置并允许用户从**搜索附近的浮动候选**明确选择其它同名匹配。候选仅搜索时出现，绝不重新显示全部知识点。
- 搜索确认与关联确认是**两个不同动作**：搜索成功只定位，选择由用户后续单击节点决定，底部「确认关联」才提交关联。

## 现有生产实现中需修正的已知位置

主组件：`src/components/KnowledgePicker.vue`。

- `pick(id)` 目前只做 `chosen.push(id)`，已选节点再点不会取消。改为使用 ID 的 `togglePicked(id)` 并保持视图、标签、可访问状态同步。
- `mind.bus.addListener('selectNodes', ...)` 当前调用 `pick()`；应按真实节点 click 做 toggle，并确认定位 API、拖拽、选区变化不会产生误选。
- `locate(id)` 目前调用 `pick(id)`，导致搜索**自动选中**，与最新要求冲突。要拆成纯定位函数，与 `togglePicked` 解耦。
- 现有搜索结果 `knowledge-picker-search` 及新增操作表单 `knowledge-picker-create` 占据纵向空间；新布局不应把所有候选长期平铺或造成整个 modal 出现滚动。结合单树规则，不能在此弹窗暗藏「新增一级知识点」入口，原节点数据不可删除。
- `confirmSelection` 保持最终确认点；取消应丢弃未确认临时态。注意真实后端关联写入与用户最近对卡片保存的**手动提交**新合同要衔接，不应自动触发卡片发布或草稿持久化。
- 小屏与图谱定位需要识别真实 `mind-elixir` 可用 API；不得通过不稳定私有 DOM 或覆盖框架事件冒充可交互。

## 真实验收清单

1. 新节点点击一次选中，第二次取消；在下方标签点击 × 反向同步图谱；多选清空/取消/确认后卡片关联一致。
2. 两个不同 ID 但名称相同的知识点可同时选择、单独移除；搜索结果用完整路径确认目标。
3. Enter 与鼠标按钮搜索完全等效，图谱居中并显示定位高亮；搜索不改变已选 count 与关联 IDs。
4. 不存在的名称：中央“知识点不存在”提示显示、约1–1.3秒后消失；连续搜索重置计时，不能叠加。
5. 弹窗的标题、图谱、已选标签、搜索、底部操作**分区固定**；全弹窗无纵向滚动；图谱能独立平移缩放，标签多时独立内部滚动。
6. 桌面 900/1366/1600px 宽和 768/900px 高度、125% 缩放：主操作按钮不被遮挡；焦点、键盘 Enter/Escape、tooltip/aria-pressed 可用。
7. GUI → 对应卡片关联确认 → SQLite 只读 → 重新打开与重启一致，取消不修改持久关联；Windows 真机结果与 Linux Electron 分开记录。
