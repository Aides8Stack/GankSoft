# v0.7.1 需求规范与实施方案

基线：已核验 SHA256 的 v0.7.0 RC。依据《问题与优化.zip》说明及14张图片；新要求优先于v0.7.0的隔离知识栏和固定浅色设计。

| 范围 | 规范化设计 | 验收 |
|---|---|---|
| P1 设置 | 设置首页为功能列表：外观主题、复盘配置说明、备份恢复、待核对操作、AI连接、操作记录、回收站；每项打开独立设置页签，复用页面管理。AI连接离开前异步保存，保留按钮；失败留在原页。不把备份/恢复等动作当成可自动执行的设置 | 页签可切换关闭；有效AI修改离页保存，非法配置阻止离开；回收站只在设置内；设置为左栏最末入口 |
| P1-1 主题 | 全局浅色/深色/系统偏好通过配置API持久化，切换立即生效；系统监听只在跟随模式生效。导图、知识点选择器及主要表面共用主题 | 重启保留；模拟OS变化；三模式下文字与控件可读 |
| P2 导航消息 | 页面栏固定于右侧工作区最上方；图标侧栏从页面栏下方开始。卡片集所有模块保留页面管理入口与子页扩展；设置有页面管理。右侧从左到右：页面管理、专注模式、消息。总览仅消息；移除本地保存标签 | 任何滚动/专注状态固定；模块页签隔离；消息为当前页子页面，返回保留原页状态 |
| P2-1 消息 | 中央通知API记录成功/信息/错误通知，可查看历史与未读状态；消息不等同完整审计日志。由统一通知桥接notice/error，防止消息历史加载再产生消息循环 | 提示消失后历史仍在；已读状态持久化；刷新后可查；不记录AI密钥 |
| P3 卡片库 | 菜单和右键共用卡片库管理门面：新建错题/记忆集、导入集、新建文件夹。每集三点入口打开编辑页，含重命名、移动、排序、导出、删除 | 所选文件夹成为默认位置；三点不触发打开集；删除确认，导出取消不提示成功 |
| P3导入导出 | 复用ganksoft.content 2.0 + ZIP容器1协议，增加可选collection元数据；ZIP内manifest校验、content和附件路径规则不变。新导入集选择名称/父文件夹，预检并事务创建/导入；失败回滚空集。完整集和所选卡片导出均使用原生保存对话框选择路径 | 有图/知识关系往返；空集保留类型；错类型/损坏包拒绝；位置正确；无学习历史冒充完整备份 |
| P4导图 | 删除版本存档页面、发布/导出服务API及模块代码；历史表保留兼容已有备份。知识栏绝对定位浮在画布右侧，不改变画布尺寸；展开页占满内容区，工具覆盖画布。底部切换大纲，封装递归大纲组件，共用同一树及保存状态 | 开关知识栏画布大小/节点坐标不变；展开无多余标题留白；大纲与导图节点一致，切换不丢草稿，五秒/离页/快捷键保存仍有效 |
| P5 时间统计 | 独立共享日期DTO、日期控件与后台只读窗口选择模块。汇总与分析均经统一统计门面请求同一自然日窗口；最近7/30天及自选首尾包含，支持全部历史；学习时区一致，拒绝非法范围，丢弃过期响应 | 两页同范围有效复盘数一致；午夜/时区/无记录/无效日期及集隔离；同一组快捷按钮+起止日期控件 |

模块只通过类型化services/API交换数据。新主题/消息元数据允许存入settings，数据库schema601及v060/data继续兼容。正式版放行仍依赖本次交付包的Win10/Win11实机验收；Linux自动化不替代实机。
