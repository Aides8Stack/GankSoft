# v0.4.7 变更与验证

设置保留复盘参数、完整备份恢复、AI连接与最近操作。回收站单独展示文件夹、卡片集、知识点、错题卡和记忆卡；可按名称和归属搜索、按类型筛选、全选当前结果或逐条勾选。恢复按容器、知识点、卡片顺序执行，失败整体回滚。单条知识点恢复支持重名时输入新名称。

彻底删除必须先获得范围预览，再二次确认。预览计入所选已删除目录的已删除子目录和卡片集、已删除卡片集内的已删除卡片和知识点，以及相应复盘历史数量。确认时再校验范围版本，拒绝已恢复、失效或变化的选择。仅清理所选范围；保留其他题目历史中的知识点文字快照。附件在数据库提交成功后清理，仅删除无其他记录引用的文件。既有备份和操作日志不因本次删除而清空。

导入确认按钮放在知识点映射与条目预览之前。预览存在错误或修改策略尚未重新预览时，按钮禁用。

验证：新增6项后端测试覆盖混合批量恢复、级联删除范围与附件、其他题目历史保护、恢复清单和会话清理、过期预览拒绝、恢复失败回滚、知识点子节点、删除后重新导入；Electron交互验证独立入口、多选恢复、范围预览、取消/确认删除、空态、980/1500/1920窗口、按钮在预览上方、策略过期禁用及实际导入。尚未在Windows 11实机验证。
