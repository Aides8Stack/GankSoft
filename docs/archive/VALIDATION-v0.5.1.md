# v0.5.1 实施与实际验证

## 改造结果

- 保留FSRS-6 / ts-fsrs5.4.2，目标保留率0.9和最大间隔继承规则不变。评估与资格过滤独立于FSRS、界面和统计。
- 猜测、记得原答案、提示、练习保存独立记录，但不改变FSRS状态、原排期或参考分。答案正确而方法理解为0/1时按方法提取失败进入Again。
- 用时不被作为遗忘的充分条件。目标未配置不评价快慢；0秒/缺失不当作效率样本；独立答对、能解释方法且超过目标，仅允许Easy降到Good，不降低Hard/Good或改成Again。
- 同日此前有效成功、随后新的独立失败可立即重学。未到期的重复成功/持续失败不重复更新；已经到期的短间隔重学仍有效。
- 当前题的独立表现按最多10个本机日历日统计，每天取最后一次有效独立结果；不足3日明确证据不足。效率只比较独立解对且能解释方法、目标一致的正数计时样本。
- FSRS估计随查看时间变化，但读取不写库；内容版本重置后，旧版本历史不会错误标成“沿用旧模型”。旧评估、旧回执和原DSR状态不重放、不补造。

## 原理与边界

新增资格过滤、效率封顶和跨日描述属于产品规则，尚未通过真实用户长期学习效果对照；测试通过仅证明列出的行为与不变量。没有训练个人FSRS参数，没有自动判断思路文字对错，不能推断同类题迁移能力。方法理解依赖用户真实自评。

原mastery平滑字段仅为兼容保留，称“复盘表现参考分”，不输入FSRS间隔计算。FSRS可提取率是模型估计，并非行测正确率。旧模型渐进承接；旧稿和旧评估不冒充新证据。

统计日期沿用本机日历日，与原每日预算/同日巩固规则共用calendarDay。用时目标更改只作用于后续评估；目标配置或题型耗时不合适时，用户应调整/关闭目标。原计时行为不在本次改造范围。

未来改变评估语义必须发布新评估版本并保留旧快照解码，不可静默修改已有评估的含义。本版未做新的性能对照，不能把v0.5.0报告中的性能数值当作v0.5.1实测。

## 复现

npm ci；npm run check；npm run test:assessment；npm run smoke:v051。迁移脚本需要可取得的旧版源码目录；本包不含真实用户数据。Windows可npm run package:portable:win；跨平台打包脚本需要对应版本的Windows图片原生包，参数见tools/package-windows.mjs。
