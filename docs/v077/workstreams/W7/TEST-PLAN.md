# W7 测试计划

所有测试使用隔离临时 Schema606 数据库。每个 CASE 独立记录 PASS/FAIL/BLOCKED/NOT_RUN、命令、环境和被测 SHA。旧 W1/W2 PASS不自动继承为W7 PASS。

## 领域/SQLite
| CASE | 场景 | 预期 |
|---|---|---|
| W7-01 | practice提交一张卡 | 立即写1条学习事件，FSRS全字段不变 |
| W7-02 | practice同卡重复提交两次 | 两条独立事件，FSRS不变 |
| W7-03 | scheduled提交一张卡 | 事件、schedule_event、scheduling同事务更新 |
| W7-04 | 正式队列5卡逐卡提交2卡后退出 | 两条事件永久保留，余3卡可恢复 |
| W7-05 | 第3卡事务失败 | 前2卡保留，第3卡无部分写入，草稿保留 |
| W7-06 | 一个卡片集创建两个scheduled队列 | 第二次返回/恢复既有会话，不创建第二个 |
| W7-07 | 不同卡片集各创建scheduled队列 | 均成功 |
| W7-08 | 多个practice队列引用同一卡 | 均可创建、保存、恢复 |
| W7-09 | practice未完成时创建scheduled | 成功，不受占用阻挡 |
| W7-10 | scheduled未完成时创建practice | 成功 |
| W7-11 | 同requestId重试创建队列 | 返回同一sessionId |
| W7-12 | 新requestId主动practice | 创建新sessionId |
| W7-13 | due与relearn同卡 | 正式队列内只出现一次 |
| W7-14 | 活动正式队列期间新卡到期 | 不插入当前快照，下一轮纳入 |
| W7-15 | 内容编辑/发布/媒体/知识点关联修改 | FSRS及dueAt逐字段不变 |
| W7-16 | 活动会话后编辑卡片 | 旧会话仍按冻结内容版本提交，事件绑定旧versionId |
| W7-17 | cycleId改变 | 阻止旧周期提交并保留草稿 |
| W7-18 | 旧未完成会话无来源标记 | 按practice恢复，不改FSRS |
| W7-19 | 旧数据多个疑似正式活动会话 | 兼容为一个scheduled，其余practice，记录完整 |
| W7-20 | 自动队列存在未完成practice会话 | due卡仍可进入正式队列 |
 
## AI数据链
| CASE | 场景 | 预期 |
|---|---|---|
| W7-21 | 导出含practice与scheduled的历史 | 全部事件导出，类型可区分 |
| W7-22 | practice事件无schedule_event | 正常导出null，不丢事件 |
| W7-23 | 未提交草稿/队列 | 不作为学习事件导出 |
| W7-24 | 创建/暂停/恢复/保存草稿后导入旧AI建议 | 数据指纹未变则允许继续校验 |
| W7-25 | 新学习事件/FSRS/内容/知识点关联变化后导入旧建议 | 来源过期，拒绝应用 |

## UI/Electron
| CASE | 场景 | 预期 |
|---|---|---|
| W7-27 | 概览无正式队列、有到期卡 | 显示固定“开始正式复盘”入口 |
| W7-28 | 概览已有正式队列 | 显示继续入口及进度 |
| W7-29 | 概览没有到期卡 | 明确显示已完成/无待复盘，不创建空队列 |
| W7-30 | 点击正式入口/连点 | 只存在一个正式队列，界面有反馈 |
| W7-31 | 卡片列表勾选同卡再次学习 | 创建自主练习，不改变FSRS |
| W7-32 | 筛选/随机/专项 | 均创建practice模式 |
| W7-33 | 从历史恢复practice队列 | 恢复指定sessionId及草稿 |
| W7-34 | 复盘过程中退出/崩溃/重启 | 已提交卡片记录不丢，未完成进度可恢复 |
| W7-35 | 返回概览 | 正式队列摘要和待复盘数量即时一致 |

## 必要命令
先运行 W7 定向用例及受影响 W1/W2 交界测试，再运行 `npm run check:protocol`、`npm run build`、`npm run test:package`。按当前仓库 Pipeline v4 规则运行必要 PR 门禁；不重跑无关旧250条人工测试。Electron必须真实启动并检查SQLite和重启读回。Windows CI、Win10/Win11真机分别报告，未运行不得写PASS。
