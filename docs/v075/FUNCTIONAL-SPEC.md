# 冻结范围与功能验收规格

本文件是**需求规格**而不是现有系统事实；源头优先级见 `00-AUTHORITY-AND-DECISIONS.md`。任何 UI/服务改动都必须能追到编号 Rxx、对应验收用例（`05-acceptance/`）。

## R01 卡片集、导航与工作台

- 学习总览以可展开文件夹和卡片集为中心，密度接近 v3.7 原型；不能改成一屏几十个巨大功能卡。
- 进入卡片集后提供概览、所有卡片、筛选学习、开始复盘、知识图谱、学习分析、导入导出、调度设置。工作区有多标签、缩略名与 hover 全名，返回原页面及浏览位置，跳转时不丢草稿。
- 一个 deck 可容纳任意组合三类卡片，不再存在 `deck.kind` 作为业务录入限制；目录只组织 deck。
- 卡片列表默认仅加载 title/type/due/score/knowledge_count 等摘要；点击可进入**详情页**，详情与编辑、历史页面分开。勾选卡片后才显示学习选中、批量导出、移到回收站工具栏。

## R02 三类卡片内容

- 单选错题：标题、题干、单选选项集合（不限 A–D，稳定 optionId）、正确选项 ID、解析、来源、首次错误思路。保存时至少两选项、一个正确答案；重排不改正确身份；选项可以增删与批量粘贴。
- 问答记忆：可编辑正面问题/背面答案/补充说明，复习先展示正面再揭示背面。
- 直接记忆：无需揭示答案或选项，阅读完整正文后评价记忆程度。
- 三者都允许使用 Markdown、数学公式、剪贴板图片/本地图片、每图独立显示宽度和知识点多对多关联；卡片引用图片必须对发布版本/历史安全。

## R03 转换、草稿、发布与剪贴板

- 切换三类卡片时总会弹确认；同意后**清除原类型的未发布草稿**，目标类型编辑草稿来自曾发布内容或首次转换建议，**正式已发布类型不变**直至发布成功。
- 一张卡片永远最多一个 draftType 和一份 draft；用户可离开再恢复；保存失败不得提示已保存。Ctrl+S 只保存草稿，不隐式发布。
- 发布执行内容版本冻结、publishedType 变更、关联和调度选择的一致事务。发布边的「重新开始学习」默认关，不另弹算法窗口；失败时保持旧版本可复盘且留草稿。
- 六向转换需提供明确映射、未映射字段标记未完成；不得自动编造题目选项/答案，不覆盖曾发布的目标内容。
- 复制卡片/Prompt 是内容剪贴板工作流；粘贴新/旧草稿先解析预览和冲突确认（含图片资源）；不是立即克隆独立卡片 ID。

## R04 外部 AI

- Prompt 生成可包含两个彼此独立的知识范围选项：①当前 deck 的完整知识点候选目录；②已人工确认的本卡知识点与父级路径；均默认关，可同时启用。
- 外部 AI 输出采用结构化 Markdown 或约定 schema 粘贴→解析→预览→用户确认→写到**草稿**；不得自动更改真实知识点关联，不接内部在线模型 API。
- 管理 Prompt 模板、最近复制内容的隐私提示；既有导入、剪贴板内容不应被静默发送到任何网络。

## R05 学习复盘与会话

- 复盘中心按卡片集调度、知识点、随机、时间区间、所选卡片等查询组合，支持随机选择知识点。题量预算、重学、专项、现有自适应队列能力应复用、不要简化掉。
- 复盘分页进度、可暂停总计时、离开自动暂停；同一活动学习会话不同分页不重复领取同卡片。
- 题目作答/揭示/自评 0.0–10.0 步长 0.1。错题客观结果独立；错误→FSRS Again 强制。每次留存选择、思路、错因、漏洞、反思可选、用时、时间戳、内容版本、映射版本、知识点快照。
- 复盘期间另一窗口发布新版：本次继续对进入时冻结的旧版判分；可记录旧版历史但不得回写新学习周期的当前调度。异常中断恢复正在作答的草稿，提交幂等，重复请求只生成一个事件。

## R06 评估与调度

- 三类卡片使用独立 FSRS 引擎的统一适配、统一自评映射；内部四档评级明确可追溯。
- 卡片集设目标保持率/最长间隔，单卡覆写优先。参数更新默认只作用今后复盘；主动批量重排需只读预览影响、执行确认；到期/逾期不允许因为重排延后。
- 重新开始学习开启新 cycle（不删除旧事件）；当前掌握度以新 cycle 有效证据计算；所有历史趋势累计保留。
- 知识点“直接/综合”两类掌握度；综合汇总去重，知识点正文不单独排程，数据不足显示待评估。

## R07 知识图谱与 Markdown 大纲

- 多根知识森林，真实节点 ID 稳定；虚拟视图根仅用于渲染，不成为业务知识节点。
- 同一父节点名称唯一，新增默认「新知识点 N」，删除后是否复用编号的策略以避免重名且可读为准（建议递增）。
- 思维导图全屏、缩放/居中/适应、搜索、布局、图标工具栏、悬停/焦点 tooltip、新增子/同级、全部展开/收起、撤销/重做；右侧只保留当前节点详情，不再重复知识点树。
- MD 大纲左侧正文按层级展示，右侧有缩进层级导航、折叠、定位；两视图同步相同节点和同一份正文。
- 空白画布左键拖动平移；普通节点拖动可移动层级或排序，重启顺序不变；**不要求拖根节点平移整图**。
- 合并/移动/删除/恢复一律处理循环关系、同级冲突、卡片多对多、正文、历史快照及图片引用；合并显式预览确认且事务化。

## R08 MD 与媒体交换

- 编辑器默认直接渲染、输入即时更新；支持中文 IME、表格、标题、行内/块级 LaTeX、颜色、图片粘贴及独立缩放；知识点编辑无显式保存节点，自动保存 Ctrl+S。
- GankSoft 自身导出的单 `.md` 用结构标记界定节点正文，允许正文标题；普通 `.md` 需在预览中人工消歧。导入可拖/选文件或粘贴，左图选择挂载点；冲突基于完整路径，默认保留原正文，允许替换或追加。
- 导出先选多根/分支，再在被选中的节点旁按需选「父级正文」「整个子树」，预览后复制/保存到选定位置。图片以内嵌 Base64 放进单 `.md`，导入转成媒体资产。
- 真正的 Markdown 富文本编辑器**未选定最终生产依赖**，先 POC，再验收，不允许用 v3.7 `contenteditable` 原型取代。

## R09 本地数据管理

- 完整备份/恢复：文件/数据库/媒体/图片引用、草稿、内容版本、全部历史、知识关联、调度、配置；恢复前保全现库，验证合法性，完成后可回滚。
- 独立追加导入卡片集：来源其他数据库的每个选中卡片集独立加入，不与现有卡片集和历史合并；必要时重映射 ID 和内部引用。相同来源版本曾导入默认跳过，允许用户强制另导一份。
- 活动数据库迁移：复制、校验、切换活动路径，保留原目录且停止写入；连接失败不能悄悄回旧库。不得将数据库直接存放不可写或易被更新覆盖的程序目录。
- 回收站：卡片、卡片集、知识节点/子树软删与恢复；卡片集整体恢复；永久删除前提示，媒体跨引用安全。

## R10 非功能、质量和交付

- 前端通过 typed protocol 调后端，不直接访问 SQLite。保持模块化与懒加载，读接口分页；学习页加载当前类型内容，不带三类隐藏正文、完整历史、大量 base64 图片。
- 事务/操作幂等/乐观锁；错误码可区分提交成功但 UI 刷新失败、已提交但响应丢失、版本冲突与真正失败；草稿不丢。
- Windows 10/11 使用已有便携 ZIP 构建/Release 流程，保证真正安装的离线 Markdown、公式、图片及 SQLite 可用。发布需用户审核，不修改现有安全门禁。
- 用户原始数据优先；旧 API 可演进/删改，但用户历史不可因此被静默删除。

## R11 现有功能保持与回归（沿袭旧版有效要求）

- 卡片批量导入后应直接可学习，不恢复已经被用户废弃的「待整理」强制状态；不同卡片集导入/学习/统计隔离，不能在“言语理解”列表泄露“资料分析”卡片。
- 已有效的历史回看折线图（得分/用时）、每次独立做题思路、复盘暂停和标签页不重复、按知识点/时间区间的筛选与随机知识点，属于保留功能；本次不能被三模式架构升级破坏。
- 完整备份应覆盖回收站内对象、所有现存卡片与记忆记录、图谱及媒体；从 gank.json/ZIP 的实际旧版数据迁移/导入需测试；不能因旧协议废弃就忽略真实用户可恢复性。
