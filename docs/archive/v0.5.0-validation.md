# GankSoft v0.5.0 修复与验收

本版以 v0.4.11 源码包和本轮15项审计问题为基线，按保护数据→业务逻辑→交互→模块边界实施。A01—A15均有对应修复；详细状态在 v0.5.0-fix-status.json。没有访问真实用户数据库，没有把测试通过解释为不存在其他问题。

## 实际验收

- 自动化：112项通过（原有87项按当前需求调整后保留，新增25项专项回归）。
- 构建：Vue/TypeScript类型检查、Electron编译和Vite生产构建通过。
- 故障：事务中途SIGKILL、两个进程相同提交、提交后丢失响应、保存失败保留输入、重试不重复。
- 历史：同题60次字段与SQL对应；内容变更保持旧快照；得分、用时分别保留空值语义。
- UI：失效题跳过、原稿续学、滑块键盘、导入隔离、重复导入、备份恢复、1100/1500/1920宽度；60/120条记录两图各点中心点击与切换键盘选择共720次。
- 迁移：真实 v0.4.0 / v0.4.10 / v0.4.11 测试库升级到schema8；旧思路、旧草稿、旧0秒与30秒原值保留，自评仍为null，跨集关联归档后解绑。
- 打包：Linux x64 ASAR实际启动、FSRS复盘、坏图拒绝及有效图重试通过。另交付Windows 11 x64程序ZIP，已完成架构、资源与依赖静态校验；未在Windows实机启动验证。

## 数据与模块边界

- 会话模块负责队列、阶段、revision和原稿锚点；工作流通过SessionPort协调复盘、回执、排期和会话，保留单事务。
- 题目模块拥有内容版本和固定内容；复盘模块写独立记录；统计是只读模型；图表只收数据并发出记录选择事件。
- 评分/日期工具独立于界面；生产调度只走FSRS，legacy算法不参与新排期。
- 图片解码属于基础设施；导入和手动入口复用。备份只在暂存目录迁移和校验，通过后才能替换正式目录。
- 筛选器有明确服务与运行时校验，不再由Application内联跨集upsert。

## 数据迁移与状态机

schema8迁移在事务内执行，并预先保存.before-v8副本。新增elapsed_value、elapsed_source、saved_filters.revision、历史查询索引和detached_knowledge_links。旧elapsed_seconds兼容列保留；展示DTO使用elapsed_value，未记录为null；旧数字来源未知，UI明确标注。原0值不能推测为缺失。

当前会话写入只接受schemaVersion=1。创建时允许省略expected_revision（等价于不存在旧会话）；已有会话必须提交匹配revision。旧会话仍可读取，由界面升级格式后写回。answer→reveal冻结原稿；reveal→result只能由复盘事务和回执完成；result→下一张需要新entry；失效当前题可跳过并保留原稿；重新作答必须留在当前题。新建会话/明确重新开始仍可创建新session。

主要错误码：VALIDATION_ERROR、REVISION_CONFLICT、CONTENT_VERSION_CONFLICT、ENTRY_CONFLICT、DECK_CONFLICT、PROTOCOL_CONFLICT、MAINTENANCE_BUSY、TRANSPORT_UNKNOWN。业务校验拒绝标为definitive；传输结果未知保留原提交重试；未分类业务错误仍以OPERATION_REJECTED兜底。

## 未覆盖与保留行为

- Windows安装、打包后启动、平台差异未实测；Windows请使用Node24并在Windows执行npm ci与package-win.cmd。
- 暂停卡片是否禁止手动有效复盘、隐藏窗口是否应停止计时仍待产品定义。本版保留：显式暂停停止、隐藏窗口继续计时、重启从保存秒数继续。
- 旧0秒语义无法恢复，不会伪造成未记录；已有损坏图片不会被自动修复。
- 全量快照、更多规模/真实用户内容、长时运行、所有平台和所有可能异常不在已验证范围。
- 保留原有按版本命名工具作为历史材料，当前发布门禁见tools/README；完整源码包中不包含真实数据库、依赖目录或旧审计注入文件。
