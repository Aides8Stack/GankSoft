# GankSoft v0.7.0 RC 实施与验证记录

日期2026-10-18。基线为恢复并核验过的v0.6.6 RC。本轮依据用户《问题和修改.zip》的P1—P7说明及16张图片实施，未将旧候选设计自动加入本轮开发。

## 当前状态

- **已实现**：卡片移集清理原知识点双向关联；新旧自动标题修复；58px图标导航；48px固定共用页面栏；知识图谱内展开页签及页面管理；图标工具与收起弹层；5秒/按钮/Ctrl+S/离页/正常关闭窗口保存；失败保留草稿及确认后重新载入；双击知识栏、拖宽及窄区布局；统一浅色导图；汇总自选日期；隐藏默认菜单；新应用图标及Windows EXE图标。
- **仅设计**：本轮P1—P7中无仅设计而声称完成的项目。
- **尚未完成**：Windows10/11实机验收与正式版放行，当前交付保持RC。
- **尚未验证**：本次Windows真实运行、Windows中文字体与DPI、中文输入法组合输入、高对比度、系统窗口/任务栏图标缓存、Defender表现及实机备份恢复。旧版本的实机或静态记录不替代本版验收。

数据库仍为schema601；既有v0.6.x的v060/data保持使用。协议2.0及58个公开方法保持兼容；未新增运行时依赖。自动标题修复只命中内部ID前缀且完全匹配旧规则的标题；不改变题目内容修订或历史快照。移集保留卡片ID、独立排期与历史作答，按目标卡片集已有规则约束排期上限。

## 关键入口

- `src/components/WorkspacePageBar.vue`：共用Home、页签、关闭与页面管理；不依赖复盘或导图数据模型。
- `src/App.vue`：按当前模块提供页面、独立作用域及导航；通过`src/composables/mapPersistence.ts`的flush接口等待图谱保存。
- `src/components/MindMapWorkspace.vue`：导图交互、自动保存、版本冲突保护与知识栏；主导图不再使用覆盖全应用的固定浮层。保存期间串行锁定画布，防止刷新覆盖后到编辑。
- `src/composables/mindMapTheme.ts`：主导图和`KnowledgePicker.vue`共用显式浅色主题。依赖源码证据：mind-elixir构造函数未收到theme时会读取`prefers-color-scheme: dark`，本轮消除了该默认路径；不能由此宣称特定Win10机器已修复验收通过。
- `electron/modules/questions/service.ts`、`electron/modules/memory/service.ts`：移集去掉原集知识点，校验新集关联，保留历史；`QuestionEditor.vue`同步清空旧关联并提示。
- `shared/question-title.ts`及`electron/infrastructure/database.ts`：可读自动标题与幂等旧标题修复。
- `shared/date-range.ts`、`CollectionSummary.vue`：按学习时区首尾包含的日期过滤。卡片总数和当前到期属于实时状态，不随历史窗口改变。
- `electron/main.ts`：移除默认菜单；`assets/ganksoft.svg`、`.ico`、`public/assets/ganksoft.png`及`tools/package-windows.mjs`：应用与EXE图标。

## 下一步与验收

解压交付Windows ZIP后运行GankSoft.exe；升级前对原有数据执行完整备份。在Win10/Win11按`docs/v0.7.0-windows-acceptance.md`执行同一交付包的自动化及24项人工验收，记录ZIP/EXE哈希、系统构建号和DPI。只有两平台全部通过且`npm run release:verify`通过，才能正式放行。不得将本次Linux或静态核对改写成Windows实测通过。
