# W8 — 现有 AI 操作链与优化后操作链逐步比较

## 真实现状（feature/v077 源码和 W4/W5 合同）

当前位置：卡片集 → 学习分析 → AI 调度调整；组件 src/unified/UnifiedAiAnalysis.vue；service src/services.ts。

### A. 旧版离线数据导出

1. 打开学习分析中 AI 调度调整子页面。
2. 在导出设置里看到全量数据说明、统计摘要日期范围、图片复选框；日期只裁剪摘要统计，不裁剪全卡/历史。
3. 如需更改 Prompt，进入编辑子页 → 保存 → 返回。
4. 点击「导出分析 ZIP」并在系统保存对话框选择位置。
5. 页面显示 writing/validating 等进度，导出在该 Vue 组件生命周期内轮询；离开时 close() 阻止忙碌离页，onBeforeUnmount 会取消 job。
6. 等待保存完成后，把 ZIP 交给外部 AI；AI 需按 prompt/analysis-prompt.md 阅读完整包后返回指定建议格式。软件本身不连接 AI。

### B. 旧版 AI 建议导入/执行（正常无冲突）

1. 返回 AI 调度调整页面，点击「导入建议 ZIP」。
2. 第一个系统文件选择器：人工选择**原始 W4 分析 ZIP**。
3. 第二个系统文件选择器：选择**AI 返回建议 ZIP**。
4. 系统按原 W4 ZIP 完整性、来源/epoch/revision、建议格式/白名单/冲突校验，展示分页预览。
5. 选择合法建议（逐条勾选或「全选全部合法建议」）。
6. 点击「校验选中建议」以打开前置确认，再点击「确认并校验」。
7. 前置校验成功后点击「执行选中建议」，再点击「确认执行」。
8. W5 执行原子事务，回执/日志/撤销条件与学习数据同步；失败/过期禁止默默执行。

以上是可见步骤拆解，不代表经过自动点击计数实测。默认无自动选中；部分步骤在 Prompt 未修改或已保存时可跳过。

## W8 方案

### A. 导出：最常用路径 2 次操作（不计导航与外部 AI）

1. 在 AI 调度调整页点击「导出供 AI 分析」：默认全部已发布卡、全部学习事件、全部知识点与调度快照，日期摘要默认全部；Prompt 沿用已保存内容；图片按用户记住的选项，首次清晰提示默认不附。
2. 选择保存位置并确认。导出由主进程任务管理，页面可离开；顶部/当前任务条展示真实阶段、计数与取消。
3. 完成后出现「打开所在文件夹」「复制给 AI 的使用说明」「继续导入建议」；用户**自行**将 ZIP 交给外部 AI。绝不自动上传。

### B. 导入/执行：正常路径 3 个用户动作

1. 点击「导入 AI 返回包」，只选择**AI 建议 ZIP**。若原分析 ZIP 记录和文件本身均可验证，不再询问用户选择原始 ZIP；文件丢失/未记录/摘要不匹配时只出现一次来源补选。
2. 系统自动来源检索、完整性校验及分页解析；展示可执行、冲突、拒绝数量与 before→after；默认勾选全部合法项，允许取消任何项。
3. 点击「应用选中建议」→ 系统自动运行 W5 原只读 prepare → 展示**一次最终确认**（真实受影响卡片、动作类别、过期/撤销限制）。用户点击「确认应用」后才进入 W5 原子事务。
4. 完成后直接显示应用结果与最近一组日志；可请求撤销，但已有后续学习或不安全状态仍须拒绝。

注意：上面的「3 个用户动作」按选文件、申请应用、最终确认统计；调整勾选属于额外自愿操作；外部 AI 操作不计入软件点击数。旧方案正常导入至少包括两个选文件 + 选择 + 两组校验/确认 + 执行确认；新方案减少了重复源文件选择和冗余只读确认，**不减少任何服务器端安全校验**。

## 旧新对照

| 关注点 | 现有 W4/W5 | W8 方案 |
|---|---|---|
| 入口 | 同页两个长区块 + Prompt 子页 | 同一页明显的「导出分析包」「导入 AI 返回包」两步 |
| 首屏设置 | 日期、附图和长篇格式提示直接显示 | 默认值 + 重要隐私提示；高级设置折叠 |
| 导出时离开 | 忙碌阻止离开；卸载会触发取消 | 主进程持有 job，切到学习页仍继续，退出软件则安全收口 |
| 导出进度 | 写入和验证计数只在当前页 | 顶部共享任务入口，真实阶段/计数/取消/结果；不虚构百分比 |
| AI 导入文件选择 | 每次必须选择原始分析 ZIP，再选 AI ZIP | 先只选 AI ZIP，最近原始 ZIP 自动定位+逐字节验证；失联再补选 |
| 建议选择 | 默认未选，需要逐条或全选 | 可执行项默认勾选并显著标数；可随时改 |
| 只读校验 | “校验选中建议”→“确认并校验” | 用户点击应用时内部自动 prepare，失败就地提示 |
| 写入确认 | 再点击“执行选中建议”→“确认执行” | 唯一一次最终写入确认 |
| 完成反馈 | 成功消息 + 独立日志区 | 顶部结果摘要、查看变化及条件性撤销 |
| 故障/过期 | 失败提示、严格拒绝 | 保留严格拒绝，提供“重新导出并分析”修复路径 |

## 数据库发生变化：旧版与 W8 对比

- **旧版**：W5 已通过 revision/epoch 校验阻止旧 AI ZIP 执行；预览可能标记 stale，并显示文字错误，但没有独立引导用户“重新导出 → 交给 AI 重新生成”的完整提醒弹窗。
- **W8**：无论在 AI ZIP 导入时、预览期间学习变化、应用前/最终提交校验中发现源失效，都弹出**一次**「学习数据库已经更新」说明；关闭弹窗仍保持建议失效，不能继续使用旧 AI ZIP。
- 点击「重新导出最新分析 ZIP」→ 本机导出新的 W4 包 → 用户交给外部 AI 重新分析 → 选择**新返回 ZIP** → 重新完整校验来源和数据库 → 可重新预览。**原 AI 返回 ZIP 不能套用新分析包。**
- 不因源文件未找到而误认数据库变化：找不到文件先补选；找到了但来源修订不等于当前库则强制重新分析。
- W8 的减少点击次数只适用于“数据库未变化、正常匹配”的普通路径；安全异常路径必须中断，不能以少点击牺牲安全。

## 子页面操作与异常路径对比

| 事项 | 当前已有能力 | W8 明确目标 |
|---|---|---|
| 页面归属 | UnifiedAnalytics.vue 内 aiPage 控制 UnifiedAiAnalysis.vue；父页面仍有筛选状态 | W8 只改 AI 子页面，不新建一级入口；返回时保留学习分析维度、搜索和时间范围并刷新数据 |
| 弹窗范围 | 旧版失效主要显示文本错误或 stale 状态 | 新版失效弹窗仅遮罩 AI 子页面，不遮盖左侧窄图标栏或顶部主导航 |
| 进度与百分比 | W4 状态仅 phase/已处理卡片数/事件数/字节 | 用真实阶段和计数；无可信总量不显示百分比，校验完成后才报告成功 |
| 数据变动后重新导出 | 旧预览失效，需要自行处理 | 弹窗引导新 W4 导出和外部 AI 重新生成；**旧 AI ZIP 永不因仅重新导出而变有效** |
| 导出期间数据变化 | 旧包固定只读快照且完整性可成立 | 正确提示包虽完成但来源已经落后当前库，不将其视为“最新可执行建议来源” |

## 必须保留的例外路径

- **原始分析 ZIP 移动/删除/篡改**：提示补选原始文件，重新做完整性与来源校验；不能仅凭 exportId 或文件名通过。
- **已学习导致 revision 变化**：旧预览/准备凭据失效；提示重新导出和外部分析，不静默覆盖新的学习。
- **AI 文件格式错误/包含非白名单动作**：显示拒绝与原因；恶意 ZIP/来源错误整包拒绝，不允许修改学习历史或 FSRS。
- **AI 建议冲突**：冲突项不可选；不把相互覆盖的不同建议悄悄应用。
- **写入回执未知**：持有原 requestId，先通过 operation.status 核对，不能二次执行。
- **撤销**：后续复盘或修订变化时可拒绝整组撤销，不强行恢复旧排期。
- **取消导出**：完成清理前显示「正在取消」，无伪完成 ZIP；应用退出不能宣称文件仍继续生成。
