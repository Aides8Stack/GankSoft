# W7 — 学习模式简化与正式复盘队列生命周期

**状态：IN_PROGRESS**

**分支：** `feature/w7-review-lifecycle`  
**数据库：** Schema606

## 目标
恢复可预测的学习流程，拆分自主练习与系统正式调度复习，取消未完成会话对卡片的占用，并确保每张卡提交后立即持久化。

## 冻结业务规则
1. 每个卡片集最多一个未完成的正式调度队列；不同卡片集各自独立。
2. 正式复盘入口固定在卡片集概览页。无活动队列时创建；已有活动队列时继续；完成后按最新到期状态创建下一轮。
3. 手动勾选、搜索/筛选、随机知识点、专项练习均为自主练习，只写学习事件，不更新 FSRS。
4. 系统到期复习及 Again 重学属于正式复习，逐卡写事件并更新 FSRS。
5. 自主练习可有任意多个队列；同卡可在多个自主队列中出现。任何未完成自主队列都不能锁卡。
6. 新建与恢复分开；一次用户启动动作只创建一个队列；同一请求重试幂等。
7. 每张卡正式提交后立即独立保存。队列未完成、暂停、退出或崩溃均不得回滚已提交卡片。
8. 卡片内容、选项、答案、解析、媒体、Markdown、类型内容及知识点关联的修改/发布均不得改变 FSRS 状态或复习日期。
9. AI 导出包含所有已提交学习事件（自主+正式、跨周期）；不把未提交草稿当作学习证据。AI 可据全部历史提出调度建议，须经用户确认应用。
10. 新建/恢复/草稿保存/暂停/切换队列不使 AI 分析来源过期；分析数据本身变化则使旧来源过期。
11. 来源无法识别的旧未完成会话按自主练习兼容；保留草稿、进度及已提交历史，不修改 FSRS。
12. 用户界面不得静默吞掉开始/提交/切换失败，必须反馈状态和可恢复操作。
