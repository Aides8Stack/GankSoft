# GankSoft v0.7.1 RC 实施与验证记录

日期：2026-10-18。基线：核验过386项源文件清单的v0.7.0 RC；依据《问题与优化.zip》及14张图片完成P1—P5。完整规范见v0.7.1-design.md，内容交换约定见collection-exchange-v071.md。

## 实施结果

设置改为功能列表与独立子页签，回收站合入设置，设置位于侧栏末端；AI配置离页和正常关窗前保存，保留手动保存按钮，无效配置阻止离开。浅色、深色、跟随系统立即生效并持久化，主画布、选择器、页面及原生窗口背景同步。

全局页面栏固定在工作区上端，覆盖侧栏上方；卡片集各模块都有页面管理。右侧顺序为页面管理、专注、消息；总览只显示消息。消息历史及已读状态持久化，打开后保留父页面，密钥形态会脱敏。

卡片库菜单、右键共用管理门面，提供新建错题集、新建记忆集、导入集及新建文件夹；三点直接进入重命名、移动、排序、导出和删除编辑。完整集/选中卡片通过原生路径选择导出ZIP；导入预检后原子创建卡片集并放入所选文件夹，取消或失败不遗留空集。

删除知识版本存档页面、三个公开方法及独立模块代码。历史导入来源表和既有内容包字段保留，兼容旧数据与备份。知识栏浮在画布右侧，不改变画布尺寸或节点位置；展开图占满内容区，底部大纲切换共用节点树，保留自动、快捷键和离页保存。

汇总和分析共用日期控件、DTO与后台只读窗口选择器。最近7/30天按学习时区的自然日计算；自选日期首尾包含，支持全部历史；非法范围不显示误导统计，过期响应不覆盖当前结果。

数据库仍为schema601，既有v060/data兼容。协议为ganksoft.content 2.0，新增可选collection元数据，63个公开方法；未增加运行时依赖。

## 交付状态

本轮P1—P5无仅设计而声称完成的项目。当前交付为v0.7.1 RC，应用内版本号0.7.1。Windows10/11实机运行、中文输入法、DPI、凭据加密、系统主题、原生对话框、备份恢复和任务栏图标仍需按v0.7.1-windows-acceptance.md验收。使用本次同一交付哈希记录结果后再执行release:verify，旧版本记录不能替代本版验收。

升级前退出旧版并备份数据，保留原版本目录；不要并行运行两个版本访问同一个数据目录。内容ZIP用于交换卡片与知识结构，不包含完整学习历史，迁移恢复请使用完整备份。
