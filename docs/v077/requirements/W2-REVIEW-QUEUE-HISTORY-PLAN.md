## 设计合同
- 复盘是独立子页面，失焦/离开/切页自动暂停，暂停遮罩仅盖复盘正文；**顶部主导航、窄图标栏和卡片集侧栏不能遮挡**；仅显式「继续复盘」恢复计时。逐卡有效耗时不包含暂停、失焦或已完成结算时段。
- 第 N 张成功评分并提交后推进；**最后一张保存成功即自动结束/归档、立即显示只读结算**，不再出现「完成复盘」/「结束队列」按钮，也无需第二次确认；失败/未知提交绝不自动结算。
- **结束是关闭并归档，不是销毁历史。** 保留会话 ID、队列顺序、逐卡评分、评级、客观结果、耗时、当次调度生成的 due 和历史。未完成队列保留进度、可以恢复。
- 「复盘历史」仅是「所有卡片」下的子页面：主页面标题区域使用**单个带数量的完整按钮**进入；不加入顶端主导航、不增加卡片列表上方一排小按钮。历史页**不放五格统计卡片**，直接展示队列列表与全部/未完成/已结束切换。
- 完成结算/历史查看共享一个组件：逐卡 `自评 / 系统` 同一格**同行**（如 `5.8 / Again`），客观/用时/当次下次复习时间；结算页仅**顶部一个返回按钮**，从历史来返回历史，从即时完成来返回起始主页面，已结束不允许修改或重新调度。

## 最多三个检查点
1. **W2.1 暂停与有效计时**：在已有 `learning.session.change`、复盘控制器/会话持久化基础上接入，失焦/切导航后刷新只保持 paused 状态，不覆盖正在保存的答案。
2. **W2.2 结算/历史读模型及 Vue**：使用 `study_sessions` + `learning_review_events` + `schedule_events` 的**事件时刻快照**；末张同一可信提交链结束会话并释放预约，不删除归档行；共享只读结算，未完成允许续做。仅增加必要的轻量批量只读投影，保持 Schema606。
3. **W2.3 定向 Electron / SQL 验收、保存与远端核验**。仅检查受影响链，不重复已通过的无关历史测试。
