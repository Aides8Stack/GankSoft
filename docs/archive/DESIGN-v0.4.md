# GankSoft v0.4 软件设计文档

设计基线 2026年10月15日

## 产品定位与对象规则

GankSoft v0.4 是本地优先的卡片学习桌面软件。以卡片集为学习单位，用知识点组织内容，通过主动学习、FSRS 定期复盘和可追溯的学习记录形成闭环。本设计依据已确认的界面草图和后续修订，作为开发与验收基准。

### 设计原则

进入软件默认打开学习总览。文件夹只分类，卡片集只存放卡片且没有子集。左侧管理目录，中间切换当前卡片集功能，右侧是一块完整内容区，整体随入口变化。基础学习和数据管理不依赖联网或 AI。

| 对象     | 归属与约束                                                                 |
| -------- | -------------------------------------------------------------------------- |
| 文件夹   | 可包含子文件夹和两类卡片集；不能直接存放卡片；禁止循环层级。               |
| 卡片集   | 分记忆积累和错题复盘两类；属于一个文件夹或根目录；创建后保留类型。         |
| 卡片     | 属于一个卡片集；可关联多个知识点；每张卡独立记录学习情况和排期。           |
| 知识点   | 属于一个卡片集，组织成树；一个知识点可以关联多张卡；可跨集关联。           |
| 学习记录 | 保存每次作答或回忆、时间、表现、笔记及调度证据；历史不会被新一次学习覆盖。 |

### 稳定编号

文件夹、卡片集、卡片和知识点使用稳定编号。改名或移动目录不改变内容关联和学习记录。名称用于展示，编号用于识别、导入更新和历史追踪。

### MVP 交付原则

v0.4 优先交付可完整使用的目录、卡片、知识点、学习、分析和数据交换流程。本文将长期目标和本版实现边界分别说明，不能把未实现的扩展当作现成功能。

## 导航与目录管理

界面采用三栏工作区；未打开卡片集时，中间栏收起并释放宽度。文件夹和卡片集可以通过右键管理，另有可见的新建按钮。

| 区域           | 内容与状态                                                                             |
| -------------- | -------------------------------------------------------------------------------------- |
| 左侧全局栏     | 学习总览、卡片库目录树、设置与回收站。                                                 |
| 中间卡片集栏   | 当前名称、所有卡片、卡片集情况汇总、知识图谱、批量导入与导出；错题类型另有分析与漏洞。 |
| 右侧完整内容区 | 根据入口展示完整页面；不划分固定的上方概况区和下方工作区。                             |

### 导航规则

点击文件夹只展开或折叠目录，不切换当前内容。点击卡片集打开它的所有卡片。切换中间入口只更新当前卡片集内容。打开全局页面或关闭卡片集时收起中间栏。启动始终进入学习总览，未完成会话通过继续学习恢复。

| 右键位置   | 操作                                                     |
| ---------- | -------------------------------------------------------- |
| 目录空白处 | 新建文件夹、新建记忆卡片集、新建错题卡片集。             |
| 文件夹     | 新建子文件夹、新建两类卡片集、重命名、移动、排序、删除。 |
| 卡片集     | 重命名、移动、排序、删除；导入导出通过卡片集入口进入。   |

### 删除与恢复

仅删除文件夹时，直接子文件夹和卡片集移动到上一级。连同内容删除时，整棵目录及所属卡片集移入回收站。删除卡片集时连同当时有效的卡片和知识点一起回收。恢复只恢复该批次删除的内容，不复活此前已单独删除的卡片。历史学习记录保留。

MVP 使用右键菜单、移动目标选择和排序字段管理目录。目录拖放排序及永久清空回收站作为后续扩展。

## 卡片内容与题目项目页

所有卡片提供搜索、筛选、列表、编辑和开始学习。错题的题目项目页是长期使用的独立详情页面，可以从列表、分析结果、知识点和学习结果跳转。

| 类型     | 主要字段                                                             |
| -------- | -------------------------------------------------------------------- |
| 共用字段 | 标题、来源、知识点关联、内容版本、创建与修改信息、学习记录及排期。   |
| 记忆卡   | 提示、记忆内容、回忆笔记；首次 MVP 以文本为主。                      |
| 错题卡   | 题干、选项、正确答案、解析、公共材料、题目和解析图片、最初错误思路。 |

### 题目项目页

项目页保留题目资料、答案解析、知识点、最初思路、长期项目笔记及复习时间线。长期笔记独立编辑，不替代任何一次复习思路。时间线展示本次答案、正误、独立性、方法理解、耗时、错因、改进、调度结果。

每次做题思路单独保存；可以选择两次历史记录并排对照。卡片内容更新后，历史答案快照和原学习记录仍保留。学习界面在提交前不展示历史思路和解析，避免影响独立作答。

### 状态与内容完整性

v0.4.5 起取消待整理状态，导入成功即可学习；缺正确答案的导入条目需在预览中排除或补齐。知识点允许暂缺。新增记忆卡需要标题、提示与记忆内容。当前错题 MVP 沿用 A 至 D 单选模板。

### 批量管理

支持选择多卡、暂停或恢复排期、移动到同类型卡片集以及删除。移动卡片保留学习历史与原知识点关联；有跨集知识点时按原关联显示。自定义标签、收藏、双向记忆卡、填空卡及记忆卡多媒体编辑为后续扩展。

## 筛选学习与学习会话

知识点筛选和随机抽取可以组合使用。随机抽取始终作用于当前筛选结果，同一轮不重复抽取同一张卡片。

| 筛选维度   | MVP 条件                                                           |
| ---------- | ------------------------------------------------------------------ |
| 文本       | 标题、正文、解析或记忆内容、来源及知识点名称。                     |
| 知识点     | 多个知识点、包含下级；匹配任意或同时匹配全部。                     |
| 学习状态   | 全部、到期、未学习、已学习、未关联知识点。 |
| 错误或遗忘 | 最近一次、曾经、最近三次有效记录至少两次；错题另有答对但不稳定。   |
| 排期与次数 | 正常、暂停、包含暂停；至少有效复盘次数。                           |
| 保存方案   | 命名保存筛选条件，之后在当前卡片集复用。                           |

### 筛选组合

不同维度取交集；同一维度多选通常取并集。知识点多选明确提供任意和全部两种匹配。筛选变化后清空旧选择，避免把隐藏卡片误加入本轮。页面显示符合条件数与已选数。

### 学习入口

支持学习全部筛选结果、手动勾选和随机抽取指定数量。只把有效、可学习的卡片加入会话。通过学习总览也可直接进入指定卡片集的到期队列，或恢复未完成会话。

### 会话保存

会话保存选卡清单、当前位置、当前答案、做题思路草稿、已展开状态、计时和练习模式。暂停返回后可继续。完成会话后清除会话任务，但学习记录永久留存。会话绑定卡片集编号，切换其他卡片集不会串写。

目标扩展包括每知识点均衡抽取、标签和时间筛选、会话完成报告以及跨设备会话同步；这些不计入首次 MVP 的已实现范围。

## 错题复盘与记忆流程

两类卡片分别使用适合的学习过程，共用记录与调度基础。错题复习必须先选择答案并填写做题思路，之后才可展示解析。

### 错题正式流程

1 读题并独立尝试。
2 选择答案并填写本次做题思路，未填写不能提交。
3 提交后展示正误、正确答案与解析。
4 记录作答依据和方法理解，按实际情况标记错因与出错知识点。
5 选填解析后的反思与改进。
6 确认建议评分，保存本次记录并安排下次。

### 思路与反思分开保存

提交前的做题思路反映当时真实判断，提交后在当前复习中锁定。解析后的反思另存，不能覆盖原稿。完全不会时也可如实写出卡住的位置。每次记录保留时间、答案和思路，并在项目页按时间线展示。

### 记忆正式流程

查看提示，尝试主动回忆，展开内容，再按展开前的真实表现选择重来、困难、正常或轻松。可以记录遗忘点或回忆笔记。保存后查看下一次复盘安排并继续下一张。

### 两种学习模式

正式复盘保存表现并调用调度引擎；练习巩固保存记录但不修改原排期。错题借助提示的记录不作为独立掌握证据。猜对、记住原答案或无法解释方法，不直接判为轻松掌握。

### 计时与暂停

仅在作答阶段累计计时，展开解析后停止。支持暂停计时、暂停返回及会话继续。学习过程中卡片被移动、删除或版本变化时，阻止按旧版本提交，并提示重新开始或跳过。

## FSRS 逐卡调度

v0.4 使用独立开源调度库 ts-fsrs 5.4.2，接入 FSRS 调度。它与 Anki 所采用的 FSRS 属于相同算法体系，但 GankSoft 不等同于完整复制 Anki 的牌组与学习选项。

| 逐卡数据       | 作用                                               |
| -------------- | -------------------------------------------------- |
| 卡片编号和类型 | 将记忆卡和错题卡的状态分开保存。                   |
| 状态和到期时间 | 新卡、学习、复习、重学，以及下一次需要复盘的时间。 |
| 难度与稳定性   | 由引擎维护，结合本次评分计算后续安排。             |
| 调度日志       | 保存评分、调度前后状态、算法版本和时间，支持追溯。 |
| 历史学习记录   | 记忆自评或题目正误、独立性、思路、耗时与反思。     |

### 评分适配

记忆卡直接使用四档回忆评分。错题依据答案正误、作答依据和方法理解计算建议评分，再由用户确认提交。答错对应重来；答对但猜测、记答案或方法理解不足对应困难；独立解出并能解释步骤为正常；能解释条件与易错点为轻松。

### 重复学习与预算

同日且尚未到期的重复练习不反复延长间隔；计划内到期重学可以正常调用引擎。练习巩固与提示学习保留记录，不更新独立复盘排期。学习总览显示完整到期数量，会话应用当前卡片集的每日预算。

### 旧数据迁移

旧学习历史保留，不伪造为 FSRS 训练记录；卡片第一次在新版正式复盘时初始化引擎状态。改变核心题干、正确答案或记忆内容后，保留旧历史并重置当前验证状态。MVP 目标记忆率使用 0.90，最长间隔沿用设置；个性化参数训练、每集独立参数预设和更丰富预算后续扩展。

参考：github.com/open-spaced-repetition/ts-fsrs；docs.ankiweb.net/manual/deck-options。ts-fsrs 使用 MIT 许可，Anki 主程序使用 AGPL-3.0-or-later。GankSoft 采用独立的 ts-fsrs 库，保留对应许可。

## 知识图谱与学习分析

知识图谱以接近 XMind 的思维导图方式展示。使用 Mind Elixir 构建可编辑画布；知识点对应真实数据，图谱中的卡片集根节点仅用于展示。

### 图谱交互

默认左右分支布局。支持双击改名、右键新增同级或下级与删除、拖动层级、撤销重做、缩放、适应窗口及搜索定位。选中知识点展示原理、方法、条件、易错点和关联卡片；可进入卡片筛选或题目项目页。

MVP 图谱修改通过保存按钮整体提交，检测版本与层级冲突，保留稳定知识点编号。删除知识点前说明将解除卡片关联。知识点详情和旧版图谱关系管理仍可进入；知识点版本存档与独立导出保留。自由关联线和图像导出后续扩展。

| 入口             | 展示范围                                                                         |
| ---------------- | -------------------------------------------------------------------------------- |
| 卡片集情况汇总   | 两类卡片集都有：卡片数量、未关联数、有效复盘、到期、暂停、近期学习量与自评分布。 |
| 记忆类汇总       | 遗忘次数和易忘记忆卡，点击可进入回忆。                                           |
| 错题类分析与漏洞 | 高频错因、反复答错题、答对但不稳定、实际错误知识点及证据入口。                   |

### 统计口径

支持最近七天、三十天和全部历史。错题正误按实际答案计算，低分不直接等同于答错。反复出错按最近三次有效作答中至少两次答错；记忆遗忘按重来评分计算。关联遗忘只表示某张易忘卡关联到该知识点，不证明所有关联知识点都遗忘。

缺少记录标为尚未验证，不当作已掌握。分析结果应能够进入对应项目页或知识点，查看实际证据。后续再增加完整趋势图、知识点覆盖变化和多时间段比较。

## 导入更新 导出与备份

批量导入与导出放在每个记忆类和错题类卡片集中。目标绑定当前打开的卡片集。全软件 ZIP 备份与恢复放在设置的数据管理中。

### 导入流程

选择 .gank.json，解析预览，确认知识点映射，查看新增、更新、复用、冲突、排除和待核对内容，再提交。错误批次整体回滚。两类卡片必须匹配对应卡片集类型，完成后刷新列表、图谱、统计和任务。

### 更新与冲突规则

namespace 加条目 key 识别同一来源卡片；目标卡片集加入命名空间以隔离不同卡片集。相同内容再次导入跳过。修订包使用新的 packageId；相同来源编号发生变化时默认提示冲突，用户明确启用更新后才覆盖。

更新复用原卡片编号并保留历史。来源未出现的本地卡片不删除。本地已删除或已移动的对应卡片不自动复活或拉回。知识点版本存档不可原地改写，修订必须使用新版本。核心学习内容变化会重新验证，不伪装为原内容继续掌握。

### 导出范围

MVP 支持当前整个卡片集导出为交换文件，包括卡片、相关知识点、关系、错题公共材料和图片。跨集关联知识点导出为可移植内容。选中卡片或筛选结果单独导出作为后续扩展。交换文件不默认包含学习历史；迁移完整学习状态使用全量备份。

### 完整 ZIP

备份包含 SQLite 数据库与附件，因此保留文件夹、卡片集、知识点、历史版本、复盘记录、FSRS 状态与日志、会话、筛选方案、项目笔记和设置。支持旧版 .gankbackup。恢复前检查校验信息、数据库与附件完整性，恢复前数据另留副本；模型 API 密钥不进入学习备份。

现有协议继续兼容 ganksoft.exchange 1.0。开发时同步维护示例与校验器。未来若改变字段语义或需要完整状态交换，应发布新的协议版本。

## 数据模型 迁移与MVP验收

沿用 Electron、Vue 和 SQLite 桌面架构。前端通过受控接口访问应用服务；应用服务以事务组织目录、卡片、知识点、学习和数据交换，调度引擎独立封装。

| 模型                          | 关键关系                                                                   |
| ----------------------------- | -------------------------------------------------------------------------- |
| folders 与 decks              | folders 递归分类，decks.folder_id 指向文件夹；decks.parent_id 迁移后为空。 |
| questions 与 memory_cards     | 分别维护两类内容；project_note 保存错题长期笔记。                          |
| knowledge 与关联表            | 知识点父子树；question_knowledge 与 memory_knowledge 实现多对多。          |
| attempts 与 memory_reviews    | 逐次学习历史；原答案和内容版本快照继续保留。                               |
| scheduling 与 schedule_events | 逐卡引擎状态及调度前后日志。                                               |
| study_sessions 等             | 会话续学、保存筛选方案、回收批次清单和导入来源对应。                       |

### 旧版升级

数据库升级至 schema 4，迁移前保留 SQLite 副本。v0.3 的父子卡片集改为文件夹归类：原卡片集本身及卡片编号不变，原子集放入对应的“原名称 的子集”文件夹。v0.2 的既有迁移仍保留。

### 验收与交付

单元测试覆盖目录循环、删除恢复、稳定关联、必须填写思路、FSRS 排期与练习模式、导入更新、图谱保存、迁移与备份。Electron 交互测试覆盖默认总览、右键管理、入口显隐、错题提交、项目历史、图谱编辑和记忆复盘。Windows 包额外校验 ZIP、完整运行文件、架构和可执行节边界。

### 当前边界

本环境可启动 Linux Electron 验证桌面流程；Windows 包使用完整的 Windows x64 Electron 运行时，交付前做文件校验，但不声称已在 Windows 11 实机验证。自动截图仅用于内部检查，不含用户学习数据。

后续扩展集中于标签与收藏、更多卡型、记忆多媒体、目录拖放、复杂图谱关系、个性化调度训练和更丰富统计，不改变本版已确定的导航与数据归属规则。
