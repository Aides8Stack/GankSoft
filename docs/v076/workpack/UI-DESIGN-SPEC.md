## 2. 统一视觉系统

- **设计语言**：安静、简洁、偏知识工具的桌面工作台。浅色中性背景 `#f7f8f7`，白色工作面，墨绿色 `#2c705e` 为主操作色；成功、警示、错误用低饱和状态色。现有主题偏蓝绿，实施时与真实亮/暗主题 token 调和。
- **字体**：Windows Segoe UI、中文使用 Microsoft YaHei/PingFang SC，正文 12–14px，标题 18–24px。重要交互应至少 13–14px，样例中 10–11px 微文本只用于次要元数据，真实编码时需检查显示缩放与易读性。
- **间距**：4/8/12/16/24/32px 递进，以 8px 为主基准。字段之间 16–20px，列表行 42–62px；轻边框替代厚重卡片与强阴影。
- **层级**：左侧 210px 左右，顶部 56px，卡片集内子导航 50px，一屏尽量只有一个主标题及一行工具栏。侧边目录用小图标和短文本，不用大型图标格。
- **按钮**：明确优先级，通常一屏只保留一个主要绿色按钮。其他操作是文字按钮或中性色；危险操作单独确认。
- **动效**：低于 200ms，响应 `prefers-reduced-motion`；打开/关闭浮窗不能触发整个页面重绘。
- **屏幕**：目标 Windows 10/11，1366×768 和 1920×1080 主验收；1100px 以内收敛次要栏，850px 以内导航图标化，更窄时侧栏可切换。缩放 125%/150% 检查弹窗和底部保存栏。
- **键盘与辅助使用**：Tab 顺序可预测，Esc 关闭弹窗，焦点返回触发按钮，图标按钮有 tooltip/aria-label；禁仅靠颜色表达状态。图谱、媒体、弹窗重点验证键盘操作与焦点锁定。

## 3. 页面逐项设计

### P01 学习总览

- 仅 4 项概要：卡片集、卡片总数、今日到期、今日完成；主区域以**卡片集列表**为核心。
- 卡片集为紧凑行（小型图标、名称、摘要、总卡数、到期数、进入箭头），不是巨型功能卡。
- 一侧提供「继续学习」和最近卡片，既不强制推荐跨卡片集队列，也不占据主区域。
- 不再按“错题集/记忆集”筛选卡片集；卡片集可混放三种卡片。

### P02 卡片集概览

- 面包屑 `公务员考试 / 言语理解` + 卡片集标题、描述、卡片数、到期数、知识点数。
- 第一优先级是「开始本集复盘」，四个辅助快捷操作为「所有卡片 / 筛选学习 / 知识图谱 / 学习分析」。
- 下方最近卡片、复盘概况使用两列，不超过两个内容块；副栏可响应式隐藏。
- 卡片集没有子集：保留“文件夹→卡片集”的目录分层，但同一卡片集下不再创建“子卡片集类型”。

### P03 所有卡片

- 默认紧凑表格：标题（可显示知识点摘要）、模式、复盘次数、最近得分、状态、操作；批量勾选。
- 统一卡片模式标识为「错题复盘/问答记忆/直接记忆」，不能用 card-set.kind 推断。
- 搜索优先，复杂筛选由「高级筛选」打开，不在列表顶部叠十余个筛选控件。
- 编辑/学习历史作为行级操作；分页/虚拟滚动，行数据只请求摘要。

### P04 筛选学习

- 筛选首行：状态、卡片类型、时间依据、时间区间。第二层是当前筛选标签和知识点入口。
- 知识点搜索或「随机知识点」为按需操作，弹出已设计的图谱 picker；筛选结果在下方列表，侧栏仅显示简明关联数量。
- 可组合时间条件（最近 7/30/90 天、自定义日期）、知识点多选（AND/OR 在“更多”中）、最近错误、已到期、未学习、历史次数等条件。
- 页面主要按钮「开始学习所选卡片」。重新筛选不能悄悄丢失尚未保存的当前学习草稿。

### P05 学习复盘工作台

- 顶部稳定展示本轮进度（当前/总数）、总计时、暂停、返回卡片集。进度条细而可见。
- 只展示**当前一张**内容，隐藏分析/知识图谱/调度设置；打开设置/历史时正确暂停计时。
- 错题：题干、可变数量单选、选择答案、揭示解析；不做多选、部分命中、自由作答。
- 问答：先正面、主动回忆后揭示背面；不用强制填写文字作答。
- 直接记忆：内容全文可见，阅读结束后自评。
- 三种模式统一 0–10 自评 + 可选思路、反思，并将有效复盘保存为独立历史事件。单选客观正误不得冒充主观得分；同理直接记忆得分不冒充正确率。
- 完成一张后提交并前进，必须在保存成功后更新进度；支持历史/调度按需弹层但不可多层互相遮挡。

### P06 编辑卡片（重点）

- **页面统一叫「编辑卡片」**，为完整工作区，不是长条滚动的小 modal。顶部仅 `复制卡片 | 粘贴卡片 | 复制 Prompt | ···`，菜单里放图片资源管理和 Prompt 管理。
- 第一行「所属卡片集」30% +「标题」70%，标题优先题目内容、自动生成保守、手动改过则不覆盖。
- 模式切换三按钮：错题复盘、问答记忆、直接记忆。切换已有模式恢复上次独立内容；从未创建的模式才触发映射候选，确认后生成草稿。
- 各内容字段用独立 Markdown/LaTeX 可视编辑器、图片粘贴自动入库、编辑区随文本自然增高；只有聚焦时出现轻量工具栏，不出现嵌套正文滚动。
- 错题：题干、选项、单一正确答案、答案解析、**「我当时怎么想的，为什么错」**。选项支持批量粘贴（换行分项），解析后每项仍可编辑多行 Markdown。
- 问答：正面、背面、可选说明；直接记忆：完整正文；共用标题、来源、知识点关联与媒体库。
- 知识点以已关联 Chip +「选择知识点」按钮展示；仅用户主动打开 picker，AI 推荐自动载入但**不自动勾选/新建**。
- 来源为简洁输入框，公共材料放可折叠区域；图片管理在「···」浮窗打开，平时不常驻页面。
- 底部有「保存为草稿 / 发布卡片」。草稿后台静默自动保存；正式发布成功后清理草稿。编辑草稿不能直接覆盖当前已发布版。

### P07 知识图谱

- 已有 `MindMapWorkspace.vue` 与 `KnowledgePicker.vue` 依赖 Mind Elixir。不要另造图谱引擎。
- 当前卡片集相关图谱默认填满画布，紧凑工具条、节点搜索、适应画布、全屏；右侧详情面板只在选择节点后出现/可收起。
- picker 是独立弹窗，顶部可交互思维导图，下方 AI 候选、搜索和多选，窗口内部局部滚动；确认后返回编辑草稿。
- 不允许右侧详情栏永久遮挡画布；保留左键平移、缩放、选中节点的 API 语义。

### P08 学习分析

- 同一张卡片跨三模式**全部历史**；概览同时展示当前掌握度、累计次数、累计用时、最近自评、错题客观正确率（仅适用时显示）。
- 大图表优先自评趋势和用时/间隔趋势，默认日期有限、可展开完整历史表。
- 知识点掌握度应汇总每张关联卡片，不把单卡频繁复盘次数直接当“知识点贡献权重”。
- 查看旧历史时保留当时版本与当时类型，不从最新题目内容回填。

### P09 导入导出

- 整卡 Markdown 粘贴使用小窗两阶段：粘贴→解析预览→整体确认导入草稿。已给字段才覆盖，没有提供的字段保留原值。
- 外部 Prompt 可修改、复制、恢复默认；仅外部 AI 工作流，本期不接内置 AI API。
- 「复制卡片」/「复制 Prompt」都支持互斥选项：整棵本集知识树 / 当前卡片相关局部关系，默认都不勾选，只复制结构化文本，不复制图谱图片。
- 全量备份/恢复保留内容、历史、知识点与图片，版本兼容由协议/数据服务验证。

### P10 设置与数据管理

- 设置左侧二级分类、右侧详情，具备返回工作台能力；复盘离开自动暂停。
- 包含复盘调度、外观、数据与备份及通用设置。
- 数据目录移动、发现和合并是高风险操作：扫描只读、展示影响范围及冲突、执行备份、用户确认后迁移；目录不可写时给出明确错误与安全退路。
- 不能把更换数据库路径当成简单的 input+按钮实现，需要单独的应用服务和完整恢复测试。

## 5. UI 的加载和性能约束（与业务架构绑定）

1. 全局总览：只获取各卡片集的 count/due/summary，不读取所有题干和历史。
2. 打开卡片集：只获取该集摘要、最近几个卡片和简要统计。
3. 所有卡片：分页/虚拟滚动的轻量列表，不因为切换筛选条件获取全部内容。
4. 编辑卡片：只获取当前模式所需字段；旧模式内容按需读取、媒体按 ID 获取；隐藏内容既不渲染也不请求。
5. 复盘：优先当前卡片，预取少量下一张卡片的**必要内容**；中断草稿单独持久化，不随页面切换销毁。
6. 历史与趋势：统计摘要单独接口，历史游标分页，不请求全部 1000 次记录。
7. 知识点 picker：用户主动打开后才获取当前卡片集子图，隐藏后销毁大型图谱实例。
8. 接口复用当前 `gank:protocol`，不能在 UI 侧绕开安全校验、事务和幂等请求机制。

## 6. UI 完成判定与可检验结果

- 主路径“总览 → 卡片集 → 复盘 / 所有卡片 / 筛选 / 知识点 / 分析”每一步操作不超过两层，导航状态可以随时返回。
- 1366×768 无菜单、主按钮、卡片列表首行相互遮挡；主要编辑字段自然增高；打开 modal 后标题与底部按钮始终可见。
- Markdown 编辑、LaTeX、图片独立缩放经过 PoC；不能仅因文本框 CSS 自适应而声称编辑器能力已完成。
- 三种卡片同一卡片集、同一历史体系，编辑/学习页面不出现“双套工具栏”和重复类型控件。
- 异常场景：失去焦点、离开、错误发布、移动卡片、数据库不可写、网络无连接（本地应用）、图片资源已被历史引用，均无静默数据丢失。
- UI 测试必须通过真实 Vue/Electron smoke 和 Windows 10/11 人工验收；**本原型不能替代这些测试**。

## 7. v0.7.5 评审修订：卡片列表、详情、草稿与回收站（2026-10-21）

本节覆盖此前 P03/P06/P10 尚未细化的用户反馈，**仅规定 UI 和预期 API 行为**，不能将原型的内存模拟误认为真实数据实现。

### P03A 卡片选择与批量操作

- 所有卡片默认用紧凑的表格样式，头部一个“全选当前筛选结果”checkbox，各行一个 checkbox；未选择时**不占用批量工具栏空间**。
- 勾选至少一项后，在搜索栏下方出现淡色窄工具条，左侧显示数量，右侧为 `学习选中 / 批量导出 / 移入回收站 / 清空选择`。按钮相互不遮挡。筛选条件改变时已选项目处理规则需要由实现确认，并明确“当前页全选”和“全部筛选结果全选”语义，不能误删不在可见范围内的卡片。
- 学习选中：以稳定卡片 ID 建立本次混合模式学习会话，进入统一复盘页，显示总数与当前卡片标题。原型只有样例队列，不是真正调度或写库。
- 批量导出：先展示**只包含已选卡片**的文件范围、格式（ZIP/gank.json）、是否附带历史/图片/知识点引用；一个确认动作后调用已有业务 Exchange 服务，不让列表直接处理文件。
- 批量删除：先展示被选标题和影响范围；确认后使用回收站服务软删除。**所有历史、媒体引用仍按现有回收站安全规则保护**；不可直接执行物理 SQL DELETE。逐条失败要返回可核对的结果，不得只提示“操作成功”。
- 点击任意卡片的标题或“详情”进入单卡详情，而不必先编辑。单卡详情显示当前内容摘要、已确认知识点、累计复盘、最近自评、图表和最近 3 条复盘；“全部历史”分页/按需读取。编辑和学习该卡是独立入口。

### P06A 编辑返回和草稿箱

- 编辑卡片标题左侧明确提供「返回上一页」；返回时维护当前卡片集、筛选条件和列表滚动/选择（只在实际实现中持久化导航状态）。若离开前草稿同步失败则警告并保留本地恢复入口，不可丢弃。
- 顶部提供次级「草稿箱」入口；所有卡片页面头部也提供「草稿箱」入口，按所属卡片集展示待发布草稿、模式、最近修改时间、继续编辑。草稿不会覆盖发布版。
- `···` 更多菜单：按真实用户习惯点击外部、Esc 或再次按菜单按钮均可关闭；不要求反复点击唯一按钮。菜单不是常驻右侧栏。

### P10A 设置中的回收站

- 设置左侧的「回收站」与通用设置、复盘与调度、数据与备份、外观、关于**同层级**；标题区有「返回原页面」，返回要回到进入设置前的卡片集及原页。
- 回收站中明确区分卡片、卡片集、知识点；显示名称、所属范围、删除日期/影响摘要。支持选择、批量恢复、永久删除，默认停留在软删除状态。
- 永久删除前必须先展示真正的卡片/知识点/历史/媒体/关联影响；提供单独警示与二次确认，且操作失败不能清空用户选择。原型仅演示这些可见状态，不销毁真实数据。
- 回收站的真实接口应沿用现有应用服务与事务/恢复模块，而不是在 Settings.vue 中重复写一套删除逻辑。

## 8. v0.7.5 评审修订：知识森林与 Markdown 导入/导出

- 一个卡片集的知识点是**多棵独立根树构成的森林**，不是必须创建一个唯一的大根节点。不同根节点独立显示；图谱视图与 Markdown 大纲视图基于同一组 ID 和父子边生成。
- 所有知识点有 `name`、可编辑 Markdown `content`、父节点 ID 或 `null`（根节点）、直接关联卡片数、含子代统计摘要。节点侧栏展示前若干行内容预览、关联卡数、子代数量，允许创建根、创建子节点、编辑 Markdown、查看关联卡。
- 图谱工作台右侧详情可关闭，不能压住画布；保留 Mind Elixir 左键空白平移、缩放、节点选择、布局和全屏能力；顶部集中必要图谱操作，不用冗余大按钮。图谱与大纲不是两套数据库。
- **导入与导出是知识图谱下面的可返回子页面**，不是挡住图谱的小对话框。布局在桌面宽度下左半部分为可缩放/展开的知识森林总览，右半部分为搜索与节点选择列表；列表选中后总览同步高亮，右侧不夺走全部画布面积。
- 导入仅支持 Markdown：可打开本地 `.md` 文件选择器，或在粘贴框输入；在右侧选择“新增独立根节点”或“挂到选定父节点”，冲突策略可预览，提交前**左侧叠加高亮标示即将新增/更新的节点**。预览不改源图谱。正式保存要通过知识点 API 的一致性事务、冲突处理和数据校验。
- 导出仅支持 Markdown：全量导出所有根，或勾选任意多棵根下的多个分支（允许跨根选取）。保留必要结构祖先标题，默认不带未勾选祖先的 Markdown 正文；右侧预览真实导出 Markdown 并显示数量。可复制文本或另存为 `.md` 文件。
- **保存位置**：正式 Windows Electron 客户端使用系统“另存为”对话框选择目录。离线浏览器原型在浏览器允许时使用系统文件选取能力，否则由浏览器下载设置控制目录，不保证每次都能选择路径。
- 知识森林的 Markdown 结构按 `#`、`##`、`###` 构建层级，节点正文是独立的 Markdown 内容。若正文自身包含标题符号，导入导出需要明确可往返的节点内容区隔协议；当前原型中的 `knowledge-md.js` 只用于界面和纯函数示意，不代表仓库现有协议。
- 注意：这里的知识图谱 `.md` 与软件全量备份 `.zip / gank.json` 是两种操作，不能混淆。

## 9. v0.7.5 评审修订：外部 AI 的知识点范围语义

外部 AI **没有预先知道这道题实际关联了哪些知识点的能力**。复制卡片/Prompt 页面提供两种互斥、默认全不选的可选范围：

- **本卡片集知识点目录（候选范围）**：可以提示 AI 从现有目录中给出匹配建议，不能宣称这些节点已经关联到这张卡。
- **这张卡已人工确认的知识点及上级路径**：只从当前卡片的真实关联 ID 获取，没有关联时明确告诉 AI“尚未关联”；名称重复时要标注路径/ID 歧义，不能猜测。

AI 生成的匹配结果只是候选，用户仍需主动打开图谱选择器确认；不自动勾选，不自动创建，不自动覆盖历史知识点关联。原型已把原先硬编码的“[已关联]”展示替换为从当前示例人工选择与森林路径动态推导的文本，但正式功能以真实数据库 ID 为准。
