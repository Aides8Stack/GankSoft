## 目标
恢复正常、简单、可预测的学习流程：自主练习不改变 FSRS；系统正式复习正常调度；正式队列按卡片集唯一；未完成自主练习不占用卡片；每张卡提交后立即记录；概览页提供固定正式复盘入口；AI 可分析全部已提交历史。

## 冻结业务规则
1. 每个卡片集最多一个未完成的正式调度队列；不同卡片集互相独立。
2. 正式复盘入口固定在卡片集概览页。无活动正式队列时创建；已有时继续；完成后按最新到期状态创建下一轮。
3. due 与 Again relearn 合并为同一正式队列，卡片 ID 去重；本轮队列创建后固定顺序，新到期卡进入下一轮。
4. 手动勾选、搜索/筛选、随机知识点、专项练习均为自主练习，只写学习事件，不更新 FSRS。
5. 自主练习可创建任意多个独立队列；同卡可在多个自主队列中出现。任何未完成自主队列都不能锁卡。
6. 新建与恢复分开；一次主动启动创建一个队列；相同请求重试幂等。
7. 每张卡提交后立即独立保存。队列未完成、暂停、退出或崩溃均不得回滚已提交卡片。
8. 卡片内容、答案、解析、选项、媒体、Markdown、类型内容、发布和知识点关联的所有修改均不得改变 FSRS、正式复习次数、学习周期或复习日期。
9. 活动会话继续使用创建时冻结的卡片内容版本；内容修改不阻止旧会话保存，学习事件绑定实际使用的版本。
10. AI 导出包含所有已提交学习事件（自主+正式、跨周期）；未提交草稿不作为学习证据。AI 可据全部历史提出调度建议，须经用户确认应用。
11. 新建/恢复/草稿保存/暂停/切换队列不使 AI 分析来源过期；分析数据本身变化则使旧来源过期。
12. 来源无法识别的旧未完成会话一律按自主练习恢复；保留草稿、进度及已提交历史，不修改 FSRS。
13. 用户界面不得静默吞掉开始/提交/切换失败，必须反馈状态和可恢复操作。
