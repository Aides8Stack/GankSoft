# GankSoft v0.4.5 测试说明

本版取消待整理状态。导入成功后直接可学习；AI解析与旧版 needsReview 字段不再阻止学习。缺正确答案的导入条目在预览报错，可排除该条后提交。已有卡片的状态在打开数据库或恢复备份时兼容转换，保留复习历史和已有排期。

仅使用以下全新原创测试数据，不使用此前示例或用户卡片。

1. 新建错题卡片集“全新复盘测试”，进入批量导入与导出，选择 examples/fresh-review-12.gank.json，预览并导入。
2. 所有卡片清空筛选后应看到12张卡、3个知识点。可以全选或随机学习，答题前必须选择答案、填写思路。
3. 保存一次复盘后检查进度、项目页的思路记录和下次排期。暂停再继续应保留会话进度。
4. 原文件重复导入不应增加卡片。导入另一个新建错题卡片集时，应独立显示12张卡和本集导入记录。
5. 如需测试记忆卡，新建记忆类型卡片集“全新记忆测试”，导入 examples/fresh-memory-6.gank.json，应有6张卡，展开答案并评分后生成排期。

“忽略以前数据”仅用于本轮测试，不会自动删除用户已有数据。测试时请选择新建的测试卡片集。
