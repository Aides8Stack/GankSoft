# GankSoft v0.6.5 RC：需求、实现与验证

日期：2026-10-17。基于v0.6.4 RC增量实现，当前交付为v0.6.5 RC。Windows10/11实机验收未执行。

## 已实现

1. 复盘页优先以复盘方案名命名，其次首个选择知识点；直接单题复盘取首个关联知识点，无关联则回退卡片集名称。长名称省略，悬停展示完整名称、来源、卡片集、题量及当前进度。
2. 页面宽度随数量和可用空间变化，最大220px、最小72px；极多页面横向滚动，页面管理入口始终可达。列表展示完整名称，支持定位及关闭。关闭需确认，已保存复盘记录保留。
3. Home图标固定40px，返回当前集所有卡片；普通导航暂停并保留复盘草稿。
4. 复盘总计时独立于逐题用时，支持手动暂停和恢复；切页、窗口blur或文档hidden自动暂停，返回及重启后手动恢复。暂停总计时同时停止逐题用时，原题目记录仍只保存逐题用时。
5. 同一卡片集允许多个不同题集独立复盘；按完整题目集合去重，题序不同仍定位已有页，原稿和进度不重置。部分重叠的不同集合允许分别打开。服务端也拒绝乱序重复创建。

## 数据与实现

完整方案与入口见源码 `docs/v0.6.5-requirements-and-implementation.md`。新增共享纯函数，复用原复盘composable、协议2.0和事务提交。前端缓存和后端保存/提交/修订/结束均按会话身份隔离。

数据库600事务升级至601，旧payload、revision和updated_at原样保留；题目、历史、调度及v060/data位置不变。完整备份支持600与601，恢复600时升级。建议升级前导出完整备份；升级后的数据库不能再交给旧程序打开。v0.5.x数据库与旧内容协议仍不兼容。

## 本地验收步骤

完整解压Windows ZIP运行：

1. 用长名称知识点选择题目开始复盘，再用已保存方案打开另一题集；确认页面缩略、悬停完整、Home按钮窄宽。
2. 打开多个不同题集，缩窄窗口；通过页面管理查看完整名称、定位和关闭。已保存记录应保留。
3. 答题中暂停总计时，确认总计时和逐题用时都停止；恢复后继续。切换Home、其他复盘页或其他应用，再回来应显示“恢复总计时”，原作答思路保留。
4. 同一题集随机改变题序再次开始，应定位已有页面且页面数不增加；不同集合各自保留答案和进度。
5. 关闭程序再启动，页面仍在、计时暂停；选择页面后手动恢复。升级前先导出完整备份，确认旧草稿和历史仍可读取。

开发检查：`npm run check`、`npm run test:package`。实机需分别运行tools/validation/windows-test.ps1并完成人工矩阵，真实双系统证据通过后才运行release:verify。
