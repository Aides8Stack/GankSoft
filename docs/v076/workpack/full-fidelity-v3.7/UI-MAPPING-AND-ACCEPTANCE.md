## P0–P2 已知纠偏清单（从已核对源码和 P2 1366px 图）
1. 正式版左侧 68px 图标栏符合后续决定，但本集导航信息层次与原型不同：核对并补充必要二级导航/路径，而非改回宽侧栏。
2. 当前顶栏与本集标题呈简化结构：需要参照 HTML 的 topbar / heading / subnav 组合校准。
3. P2 复盘概况从原型「掌握度/进度/持续掌握/建议加强」改为「平均自评/今日完成/单选正确率」：必须按真实可用指标做视觉结构复刻并记录字段映射；不能填充假 76%。
4. 核对按钮图标、提示语、标题字号、区域容器宽度、边框、内外间距、最近卡片行信息与空白占比。
5. P1 空数据和合成非空状态应双态比照；所有截图须对应已运行的正式生产入口，不能把测试断言通过算视觉 PASS。
