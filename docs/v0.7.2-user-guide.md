# v0.7.2 使用与升级说明

## 安装与升级
退出旧版，先从旧版设置→完整备份与恢复导出完整备份。把本版Windows ZIP完整解压到全新目录，再运行GankSoft.exe；不要只复制EXE，不要在ZIP内运行，不需要安装npm/Node。保留DLL、resources、locales。数据沿用v060/data，schema601，没有另建学习数据库。

## 图片录入
进入所有卡片→新增错题卡或编辑。题干填写文字或简短图片说明，选择正确答案；在题目图片/解析图片区点击导入图片，支持PNG/JPEG/WebP；也可截图后点击粘贴图片，或聚焦图片区Ctrl+V。输入框仍是纯文本，图片在独立区域管理。保存前即可预览、删除和拖动显示宽度；保存时统一生效，取消不改原卡片。详情不再增删基础图片；查看原图、缩放、旋转请点击图片。
作答阶段在本次作答图片区增删图片，揭示解析后冻结原作答证据；提交后在复盘记录详情查看。原图不因显示宽度被压缩。完整备份包含图片和作答历史，卡片集内容ZIP不含完整学习历史。

## 旧版待核对锁
若旧版粘贴已经出现“上次系统操作结果未知”，升级不会自动清除该锁。先查看原卡片是否已添加图片，确认没有遗漏/重复；进入设置→待核对的系统操作→记录核对结果并解锁，按界面填写实际核对说明，然后回编辑页操作。解锁不会撤销或重做旧操作，切勿未核对就反复点击。本版无图片、读取失败会明确报错，不应新增未知锁。若操作回包丢失，本版先按原请求核对已提交回执；确认成功则恢复结果，仍未知则保留待核对状态，不自动重复提交。

## 学习工作台
左栏搜索并勾选知识点，可包含下级和OR/AND；右栏搜索、日期和高级条件组合。有限日期范围不包含无学习日期的卡片；创建时间独立可选，导入时间不可用。自选区间需点击应用，非法值保持原条件。筛选方案按集保存，7/30天为相对表达式。
随机知识点先抽取预览，再替换或追加选择；条件变化需重抽。少复盘优先按有效复盘次数计算，不是掌握度。手动选卡与当前匹配独立，底部明确显示不在当前结果中的已选数；学习所选与学习筛选结果各用各自范围，开始前确认。默认排除暂停，可在高级筛选中改变，不会解除暂停。

## 导图与页面
展开导图按钮在顶部画布工具栏。新增知识点使用本集同父节点下当前最小空缺编号，删除编号可复用。页面管理连续逐行关闭时保持展开，全部关闭需确认；已保存历史保留，未完成页面结束。点击范围外、失焦、Esc收起。

## 验证状态
本版为0.7.2 RC。Windows10/11本机原生对话框、剪贴板、主题、DPI、输入法、Defender及完整备份恢复尚未实测；按Windows清单验收。EXE未开发者签名。暂存图片为避免误删草稿不会自动清理，可能保留未关联文件；可以通过完整备份保留，不要自行删除附件目录。
