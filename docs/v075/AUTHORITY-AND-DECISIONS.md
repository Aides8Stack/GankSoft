# 最终需求权威与决策账本 — v0.7.5

## 优先级

**用户最近明确确认 > 本文件 > 本包的业务规格/接口规范/验收 > v3.9 总结 > v3.7 设计稿 > 早期 UI 原型记录 > 需求.zip 与改进.zip**。任何冲突由本文件覆盖；若 Work 发现本文件内部逻辑矛盾，暂停相应模块的危险写操作，记录证据后仅询问必要决策，不默认猜测。

## 已确认：产品与卡片

- DE-01：卡片集组织学习，不区分卡片集的问答/错题类型，不含子集；同一卡片集允许混合三种卡片：错题单选、问答记忆、直接记忆。目录/文件夹可组织卡片集。首页仍以紧凑小图标和卡片集目录为主。
- DE-02：稳定 cardId，三种模式保留各自曾**发布过**的内容；六向映射仅用于目标模式首次初始化建议，不覆盖已有已发布内容。
- DE-03：同一卡片最多一份**单类型**未发布草稿。用户点击切换类型必须先确认；确认切换时原类型未发布草稿**清除**，旧版已发布内容/历史不删。目标模式先进入编辑，只有成功**发布**才改变 `publishedType`。
- DE-04：草稿自动保存（Ctrl+S 可主动保存），发布独立原子操作。发布旁「重新开始学习」复选框**默认不选**，不主动弹出额外调度选择窗口。只有用户选重学才开启新的当前学习周期。
- DE-05：复制卡片是**复制内容到剪贴板**，可粘贴到新草稿或已有草稿，先预览覆盖内容并确认；**不做单击即克隆数据库卡片**。跨卡片集粘贴新卡片不继承历史/关联。跨卡片集“移动”是真实移动，保留卡片身份历史。

## 已确认：复盘与调度

- DE-06：0.0–10.0 分，步长 0.1。错题客观对/错与主观自评分**分开**，允许错题选错打高分/答对打低分。
- DE-07：映射 0.0–5.9→Again；6.0–7.4→Hard；7.5–8.9→Good；9.0–10.0→Easy。错题**客观错误无条件 Again**；实际映射评级与自评都保存。
- DE-08：所有学习事件、答题思路、用时、客观结果、知识点**当时**关联 ID/名称/父级路径快照、内容版本和规则版本永久保留。当前掌握度使用现在关联与当前学习周期，不改写历史。新周期零记录时「待评估」。
- DE-09：知识点本身**不成为独立调度对象**；直接掌握度按直接关联，综合按自身和全部后代关联卡片、按 cardId 去重。
- DE-10：卡片集全局调度设置 + 单卡局部覆盖；修改全局参数不自动改既有排期。主动发起重算必须预览确认；原本已到期/逾期卡片不得因此延期；单卡覆盖优先且不受全局改动影响。
- DE-11：复盘开始冻结内容版本，允许完成并将事件归档到旧版本；若新版学习周期已变化，不允许旧事件写坏新调度。会话可恢复、计时暂停、同一会话不重复抽同一卡片，提交幂等。

## 已确认：知识森林/Markdown

- DE-12：每个卡片集可有多根知识树，同父名字唯一，新节点默认「新知识点 N」并递增；不同父可重名。
- DE-13：思维导图全屏、紧凑图标+中文悬停/焦点名称；不显示冗余知识点导航；右侧详情与正文。Markdown 大纲在右侧有可缩进、可折叠的层级目录。两视图同源。
- DE-14：左键拖空白区域平移全图，**普通节点**拖拽调父子关系或同级顺序；排序要持久化；合并必须先预览正文/子树/关系/冲突并确认，不能仅靠碰撞自动合并；支持撤销/重做。
- DE-15：删除父知识点整棵子树进入回收站，卡片和历史不删除；恢复时若缺父/同名需由用户选择挂载、重命名或取消。事务完整。
- DE-16：知识图谱跨卡片集复制只复制结构、正文、图片；不复制卡片、关联、历史。MD 导入同完整路径冲突可选保留/替换/追加，默认保留并预览差异。
- DE-17：知识点 MD 正文允许标题。GankSoft `.md` 交换格式**采用 HTML 注释结构标记**区分节点标题与正文内标题；普通 MD 无标记时人工预览消歧。单 `.md` 图片以 Base64 Data URI 内嵌；与完整备份格式完全不同。
- DE-18：Markdown 默认**边写边渲染**；知识点内容自动保存并 Ctrl+S，不额外提供常驻“保存节点”。图片可各自调整显示宽度并持久化；支持 LaTeX。外部 AI 复制 Prompt 两个知识范围复选框独立且默认均关，AI 不自动写入真实知识关联。

## 已确认：数据安全

- DE-19：「完整恢复」与「从其他数据库**追加独立卡片集**」是两种操作。后者不跨数据库合并卡片正文、事件、图谱或 FSRS；每个导入卡片集独立生成本地对象身份与内部关系映射，同名也不合并。同来源同版本重复导入默认跳过提示，允许人工强制再次导入独立集。
- DE-20：数据库迁移先复制数据库/图片并核验，再切换唯一活动路径；**原目录保留且停止写入**，活动目录失联不自动写回旧库。
- DE-21：删除卡片集整套内容逻辑移到回收站，恢复整体；永久删除前高风险确认。历史、已发布内容、图片被引用时不可误删。
- DE-22：跨卡片集移动卡片保留 cardId、历史、FSRS 当前状态和单卡覆盖，解除原知识点现行关联、目标集需重选；新集的全局调度参数适用于后续排期。

## 最终暂缓/禁止：不要因读旧资料而恢复

- EX-01：**拖动根节点移动整张思维导图**；用户最新明确表示暂不考虑。只保留空白画布拖拽平移，不引入独立根自由绝对坐标。
- EX-02：错题多选、部分命中、自由文本作答；只做单选。
- EX-03：卡片集按卡片类型限制；卡片子集；自动生成卡片副本。
- EX-04：一份草稿同时有多个类型、切换类型不清草稿、切换类型立刻改变已发布类型。
- EX-05：自评强制与正误分段绑定（“正确≥6 / 错误<6”旧规则）；客观正误与自评现在独立。
- EX-06：AI 自动建立知识点关联、软件内调用外部大模型 API。
- EX-07：无结构标记的 GankSoft 专用 MD 交换、正文标题一律算节点的旧规则。
- EX-08：**跨数据库同 cardId 合并历史/自动 FSRS 合并**。数据库追加是独立卡片集，不拼卡片、不去重跨卡片历史。
- EX-09：重写现有 Windows 便携包发布流水线、自动合并 PR、自动发布 Stable。
