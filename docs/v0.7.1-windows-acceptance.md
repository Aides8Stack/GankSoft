# v0.7.1 Windows 10/11 实机验收

当前两平台均为 **not_run**，不放行正式版。必须用本版同一交付ZIP分别在Windows10 x64（19041及以上）与Windows11 x64验证；记录实际构建号、DPI、ZIP及EXE SHA256。旧版本验收不得复用。

安装Node24+并在源码目录npm ci（仅测试机需要），解压本版Windows ZIP，然后运行：

```powershell
powershell -File tools/validation/windows-test.ps1 -ExePath C:\GankSoft\GankSoft.exe -ExpectedOs win10 -ZipPath C:\GankSoft-v0.7.1-RC-Windows-x64.zip
```

另一台机器改为win11。自动化通过会生成`validation-results/win10-actual.json`或`win11-actual.json`，人工逐项执行后再填写manualCases及manualSignoff；不得直接批量改为passed。`npm run release:verify`要求两个文件均为本版、24项通过、签名检查与自动化通过且使用同一ZIP/EXE。
