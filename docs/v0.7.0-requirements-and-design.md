# GankSoft v0.7.0：问题解析与规范化设计

依据：用户上传《问题和修改.zip》中的 `问题/problem.md` 与 image.png、image-1.png 至 image-15.png。基线为 v0.6.6 RC。本文件先定义需求与验收，最终实施及验证状态另见同版验证记录。

## 需求与行为

| 编号 | 用户意图及规范化行为 | 验收标准 |
|---|---|---|
| P1-1 | 移动卡片后解除原集知识点的双向引用；新集可重新选择知识点。取消编辑不发生移动。卡片 ID、独立复盘记录和历史证据保留，不抹除历史错因 | 从甲集移到乙集后，甲集卡片列表和知识栏均无该卡；乙集仅显示新集关联。前后卡片 ID、历史记录一致 |
| P1-2 | 自动标题使用题干去除多余空白后的前36个字符，超长加省略号；空题干为“图片题”。标题无需重复所属集，绝不显示内部 ID。仅修复严格匹配旧生成规则的 ID 前缀标题，自定义标题保留 | 新建空标题得到可读题干；重启修复旧标题且不改变题干、内容修订与作答历史 |
| P2 | 中侧栏缩为58px图标导航；42px整块可点击，悬停或键盘聚焦显示功能名；保留关闭卡片集 | 图标可辨识、tooltip不被导航栏截断；卡片、知识图谱等导航可用 |

| P3-保存 | 每5秒保存已提交的节点修改；输入节点名称时不抢输入焦点，完成输入后进入下个保存周期。离开原页/展开页/模块前先提交编辑并等待保存；支持按钮、Ctrl+S及正常关闭窗口保存。保存失败保留草稿并阻止离开；提供重试，以及明确确认后重新载入已保存图谱的恢复入口 | 五秒保存、离页保存、快捷键和重开持久化均验证；并发/非法树保存失败不得显示成功；保存期间串行并短暂锁定画布，避免后到编辑被刷新覆盖 |

| P6 | 隐藏Electron默认File/Edit/View/Window菜单栏，保留系统原生窗口标题栏与最小化/最大化/关闭 | 启动后无默认菜单，Alt不唤出默认菜单；正常窗口控制可用 |
| P7 | 新设计圆角矩形图标：绿色卡片叠层、G与复盘勾号；保留可维护SVG源、多分辨率ICO及透明PNG；应用内、窗口及Windows EXE使用同一标识 | 图标资产完整；EXE资源包含自定义图标，实际桌面缓存/缩放由Windows验收 |

## 模块边界与数据保护

`WorkspacePageBar.vue`仅负责展示与弹层生命周期，不依赖复盘/导图业务；`App.vue`提供当前模块页面与路由。`mindMapTheme.ts`统一主导图及知识点选择器的浅色主题。`mapPersistence.ts`只暴露异步flush边界，导航不依赖导图库。导图树持久化继续使用现有 `knowledge.map.save`，保留预期版本检查、事务与结构校验；协议仍为2.0，不新增不兼容API。日期范围纯函数置于 `shared/date-range.ts`，只负责日期判定，不改变排期。

数据库schema601及v060/data保持兼容，不新建空数据空间。标题修复幂等、严格限定旧自动生成格式，不批量改写人工标题，不改历史快照。移动时清除当前关联表中的旧集引用，历史作答证据保持原貌。无新增联网功能或运行时依赖。

## 验证与放行边界

v0.7.0是开发与交付版本号；Windows正式版放行必须有对应本次新包哈希的Win10/Win11实机结果。历史v0.6.6通过记录不得用作本版通过证据。Linux业务测试、Electron界面测试、ASAR及Windows包静态验证分别记录；未执行一律标注not_run。系统强杀、断电或进程崩溃不保证最后五秒未保存修改落盘。
