# GankSoft v0.4.6 界面更新

本版继续使用 GankSoft v0.4.5 代码，仅参考 PickQ 与 MistakeBook 的界面设计，没有改换应用底座或复制其组件代码。

## 页面

统一浅灰白背景、低饱和绿色强调色、可见焦点、边框与圆角。保留文件夹和卡片集导航。总览增加下一步操作区，按当前筛选优先恢复未完成会话，否则开始到期复盘。卡片列表区分筛选、学习操作、列表内容，随机数量放在随机练习菜单中。复盘页显示本张三个阶段和本轮进度，右上角专注模式可隐藏侧栏，显示导航恢复。题目项目页时间线展示每次答案、用时、依据、知识漏洞、思路和解析后反思。

## 验证

49项单元测试及构建通过；Electron完整流程验证目录操作、错题思路必填、FSRS、记忆学习和图谱；980/1100/1280/1500/1920像素卡片列表无外层横向溢出；随机菜单、专注模式切换不丢草稿、保存知识漏洞和反思、返回列表验证通过。新12张错题与6张记忆卡通过实际导入和学习流程。复盘进度、暂停续学与完成流程通过验证。

数据结构和调度算法没有因本次界面调整而变更。Windows压缩包完整性检查和独立应用启动另见交付结果；未进行Windows 11实机验证。随包v0.4设计PDF为基础设计，最新界面以本说明为准。
