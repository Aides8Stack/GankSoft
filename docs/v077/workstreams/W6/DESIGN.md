# W6 — 设计与接口合同

**需求来源：** 用户于 2026-11-01 提供卡片详情截图并明确要求紧凑布局、题干与选项同组、答案与解析同组、学习统计同组；知识点按钮不得跳转知识图谱，而应展示当前关系并在详情页直接修改。关联 [Issue #37](https://github.com/Aides8Stack/GankSoft/issues/37)。

## 1. 页面信息架构

页面只保留卡片标题、模式/来源和必要操作。主体按三大区块组织：

### A. 题目与选项（question-v1）

- 题干/材料置于选项之前。
- 选项使用字母固定列 + 文本列，桌面端两列网格；字母与文本同行起始，文本超长时只在文本列内部换行。
- 小屏改为单列，保留字母列固定宽度和文本最小宽度 0。
- 不再把每个选项渲染成独立的大型 section；减少重复标题和分割线。

### B. 答案与解析

- 正确答案和解析属于同一个内容区块。
- 正确答案有清晰但克制的标识；解析保留 Markdown 和媒体引用。
- 不把答案、解析散落在题目区块以外的独立卡片。

### C. 学习统计

- 累计复盘、最近自评、观察次数、记录完整性同一摘要行。
- 学习趋势、最近学习记录在同一个统计容器内；宽屏并列，小屏上下排列。
- 完整历史保留折叠展开和原有分页/单次记录证据。
- 统计仍由现有 `learning.mastery.card`、`learning.history.list` 和原有趋势组件提供；不得新建计算口径。

## 2. 卡片模式

- `question-v1`：题干/材料 + 紧凑选项 + 正确答案/解析 + 来源/思路（如有）。
- `qa-v1`：问题/答案/补充，使用紧凑双区块，不显示单选选项。
- `direct-v1`：正文独立展示，保留 Markdown/媒体。
- 所有模式保留现有图片、Markdown、媒体引用和历史快照能力。

## 3. 知识点关联管理（当前详情页内完成）

### 展示

- 首屏读取 `knowledge.cardLinks.get` 和 `knowledge.tree.read`。
- 显示每个已关联知识点的名称及完整祖先路径；无关联时显示明确空状态。
- 读取中/失败/节点已失效分别呈现，不用“已关联知识点”假数据冒充真实名称。

### 修改

- “修改关联”只打开现有 `useKnowledgePicker().open({deckId, initialSelectedIds, purpose:'association', allowSelectDescendants:true})` 选择器；不得调用 `switchPage('knowledge')`。
- 选择器确认只更新页面暂存选择，不写库；页面显示待保存变更及“保存关联 / 放弃修改”。
- 保存调用现有 `knowledge.cardLinks.set`，携带读取到的 `revision` 作为 `expectedRevision`，沿用原 requestId 和 CAS。
- 保存成功后必须再次 `knowledge.cardLinks.get` + `knowledge.tree.read`，以持久化回读结果覆盖暂存状态，并逐项核对集合。

### 关联集合验证

令旧集合 O、新集合 N：
- 新增：N − O 必须全部存在；
- 断开：O − N 必须全部不存在；
- 保留：O ∩ N 必须全部存在；
- 重复 ID、跨卡片集 ID、已删除节点由现有协议拒绝。
- 若 revision 冲突，保留用户暂存选择，提示重新读取；不得自动覆盖外部更改。
- 若命令结果未知，保留原 requestId/payload，不重新生成写请求；先核对 operation receipt/重新读取关系，不能把未知结果提示为失败或成功。

### 数据保护

- 断开关联仅更新卡片关系，不删除知识点节点。
- 历史事件的 knowledge snapshot 是事件时刻证据；修改当前关系不得重写历史快照。
- 不改 Schema606、FSRS、ReviewEvent、schedule_events、掌握度算法或统计口径。
- 页面数据刷新继续使用 `useDataRefresh` / `dataSync`，旧响应不能覆盖新结果。

## 4. 无障碍与响应式

- 选项行和知识点操作可由键盘访问，按钮有明确文字/aria-label。
- 900/1366/1600px 检查布局；选项字母/文本同行起始，长文本不造成页面横向溢出。
- 窄屏选项和统计改为单列；按钮换行但不挤压内容。

## 5. 范围外

- 不改学习统计 API、趋势计算、历史事件协议。
- 不改知识图谱主页面、节点编辑、树导入导出。
- 不新增服务、Store、IPC、数据库表、迁移。
- 不改普通卡片内容 ZIP、W4/W5 或旧 250 CASE 总账。
