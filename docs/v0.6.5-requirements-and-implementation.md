# GankSoft v0.6.5 RC：答题页面升级方案与实现

基线：v0.6.4 RC；版本：0.6.5；日期：2026-10-17。五项用户需求均已实现；Windows10/11实机验收未完成，保持RC。

## 需求与行为

| 用户需求 | 已实现规则 | 验收方式 |
|---|---|---|
| 页面名称与缩略 | 优先使用当前已应用且未被修改的复盘方案名称；其次首个筛选知识点；直接学习时取第一题的首个关联知识点；无知识点则使用卡片集名 | 用长知识点和长方案分别启动；标签省略，悬停看完整名称 |
| 页面管理与宽度 | 标签共享剩余宽度，最大220px、最小72px；文字省略后，极多页面横向滚动；固定页面管理入口展示完整名称、来源、题量，支持定位和关闭 | 12页在1100px窗口检查，无主区域横向溢出；管理列表定位和关闭 |
| Home图标 | 固定40px主页按钮；返回当前卡片集所有卡片，未打开卡片集时返回学习总览 | 检查图标与提示，往返不丢草稿 |
| 总计时 | 独立累计整轮复盘时间，包含作答、解析反思及结果停留；完成后停止。支持暂停/恢复；导航、blur、hidden均暂停；回到页面及重新启动后须手动恢复 | 暂停前后比对总计时及逐题用时；离页、失焦和重启复验 |
| 不允许重复题集页面 | 对卡片集ID及去重排序后的完整题目ID集合判重，忽略顺序；相同集合定位已有页并提示，不清除原稿。部分重叠集合允许分别打开 | 单题重复、全结果与随机同集合测试；协议层拒绝乱序重复创建 |

“页面关闭”结束该页未完成会话草稿，需确认；已保存逐次复盘记录保留。普通导航只暂停并保存，不关闭页面。页面管理通过持久会话重建，程序重启后页面仍在。

## 模块与数据

- `shared/study-pages.ts`：题集身份、总计时格式化纯函数。
- `src/App.vue`：页面展示、命名、导航、判重、管理；导航等待当前草稿保存成功，再切换页面。
- `src/composables/useStudySession.ts`：逐页草稿、计时与保存生命周期，监听离页/失焦/隐藏，独立总计时与逐题计时。
- `src/components/StudyWorkspace.vue`：总计时和手动恢复入口；原逐次作答与历史统计流程保留。
- `src/services.ts`：协议缓存改用sessionId，避免同一卡片集的会话互相覆盖。
- `electron/modules/sessions/{events,service}.ts`、`electron/protocol/gateway.ts`：全部保存、揭示、提交、修订号、结束操作按deckId+sessionId隔离，服务端判重。
- `electron/modules/trash.ts`：按行处理会话清理，避免同集多个草稿被一并覆盖。
- `shared/protocol/data.ts`：既有Draft增加pageTitle/pageDetail/totalSeconds/timerPaused，沿用统一桥、2.0契约和状态机；已导出协议文档。

数据库从600升级到601：将原每卡片集唯一行调整为多行，使用卡片集与payload.sessionId唯一索引。升级在单事务内完成，原payload、revision、updated_at原样复制；不迁移题目、历史或调度数据，不更换v060/data路径。600/601完整备份均可恢复，恢复600时同样升级。升级后数据库不能由旧版打开，请升级前导出完整备份。

## 验证和限制

实际结果与命令见同版本交付报告及 `validation-results/check-v065.log`、`asar-v065.log`、`study-pages.json`、`windows-package-v065.log`。

测试入口：`npm run check`、`npm run smoke:study-pages`、`npm run test:package`。Windows脚本加入新页面回归，但尚未实际在Windows运行。

界面自动化中窗口失焦通过派发blur事件验证监听逻辑；关闭确认使用confirm替身。Windows原生焦点、最小化、原生确认框、字体/DPI、休眠唤醒仍待Win10/11人工验证。计时按页面活动秒累计，不计算页面离开或程序关闭的时长。Windows实测记录不得用Linux结果或PE检查替代。约845KB主JS分块警告仍保留。
