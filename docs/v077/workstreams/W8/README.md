## 真实页面层级

卡片集工作台 → **学习分析（父页面）** → **AI 调度调整（W8 子页面）**。必须保留窄图标栏和顶部导航，W8 返回学习分析且保留原维度、日期、搜索等条件；失效弹窗只覆盖 AI 子页面内容区，不遮挡主导航。完整合同见 [CONTRACT.md](./CONTRACT.md)。

## 首要目标

1. AI 分析 ZIP 导出默认一键发起，保存位置只选一次；完整数据范围和日期含义不变，Prompt 与图片选项收进高级设置。
2. 导出在 GankSoft **仍运行时**允许切换页面和继续学习，顶部任务状态可见；真正的进度、取消、失败清理由后台任务持有。
3. AI 返回 ZIP 导入优先只手选返回包；系统根据此前实际导出记录找到原分析 ZIP，**再次完整核验原文件**。查找失败时才手选原始 ZIP，绝不跳过 W5 来源安全校验。
4. 建议预览默认勾选全部**合法**建议（仍需用户检查和确认），冲突/拒绝项不可执行；用户点击应用后自动执行已有只读准备，最后只做一次写入确认。
5. 只有用户最后确认才执行已有 W5 四种白名单调整，整组原子提交、失败整体回滚、保守撤销与回执恢复保持不变。
6. **数据库版本/修订发生实际变化必须弹窗**：旧 AI 建议立即失效、停止应用，提示重新导出最新学习数据并交给外部 AI 重新生成；可暂不处理但不能解除失效锁定，重新导出的新 ZIP 不自动使旧 AI 建议重新有效。
7. 结束后可查看受影响卡片、应用记录、撤销条件；AI 为离线外部工具，不自动上传数据、不自动调用 AI、不自动导入任意文本。
